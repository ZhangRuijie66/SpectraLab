## 🆕 一、寿命拟合新增「时间单位」全局设置（纳秒 / 微秒）

**做什么**：荧光寿命参数组最上方新增 **「时间单位: 纳秒 (ns) / 微秒 (μs)」** 下拉框。
选 μs 后，τ 全部按微秒读写——几十 μs 量级的样品（如 1O2 磷光）不用再数
`1000` / `1000000` 这种 0。

- **它管什么（输入 + 显示）**：
  - 输入：`τ_min`、`τ_max`、`固定 τ`（标签也变成 `τ_min (μs):` 等）；
  - 显示：拟合图与诊断图的**时间轴**、寿命分布图的 **τ 轴**、信息页与分量表里的
    τ 数值、分量图例 τ、IRF 位移量、叠加分布图的 τ 轴；
  - 批量产物：跨样品汇总图（τ 轴）、PDF 报告（表头 `τi (μs)` 与各样品页）、
    「导出当前拟合结果」的 CSV/XLSX 汇总表与 md 报告（列名 `τ1(μs)`、`拟合区间(μs)`…）。
- **它不改什么（重要）**：内部拟合**始终按 ns 计算**——速率网格 `k = 1/τ(ns)`、
  χ²R、分量个数与占比都与单位无关；结果 dict / json 里 `tau_*_ns` 永远以 ns 记录。
- **切换单位时输入框数值自动换算**，物理范围不变：`1000 ns` 切到 μs 后显示 `1`，
  切回 ns 又是 `1000`；固定 τ 同理（`60, 100` ns ↔ `0.06, 0.1` μs）。
  当前画布用**已有拟合结果**按新单位重画（几十毫秒），**不会重新拟合**。
- **全局性**：单位随会话记住，下次启动自动套用；所有文件、所有批量操作共用。
- 「存为默认值」保存的 τ 范围与固定 τ **一律按 ns 存**，所以默认值的物理含义与
  显示单位无关——换单位不会让默认范围悄悄变 1000 倍（套用时会换算回当前单位）。
- 模块侧同步支持：`plot_lifetime.py` 的 `build_summary_table / _format_report /
  export_fit_results / plot_summary / export_report_pdf / plot_result /
  fit_lifetime` 都新增了 `time_unit='ns'` 关键字参数，命令行加了
  `--time-unit {ns,us}`。**默认 ns 时输出与旧版逐字节一致**（已用 git HEAD 版对比验证）。

## 🐛 二、修：寿命模式改「绘图标题」画面不更新（用户反馈）

**症状**：在寿命模式把「绘图标题」改成 `Ce6 lifetime` 后，画布仍是上一个样品的旧标题
（`R101 13.3μM`），导出的 PNG 也还是旧标题。

**原因**：寿命模式的实时更新被整体关掉（重算一次 1–2 分钟，`_trigger_live_update`
直接 return），而标题输入框的信号走的就是这条路径 —— 于是"改了没反应"。

**修法**（`_rerender_lifetime_cosmetic`）：寿命模式下，标题 / 线宽 / 颜色这类
**纯外观**参数改动，直接拿**上一次的拟合结果**重画三张画布（主图 + 寿命分布 +
拟合诊断），几十毫秒完成、**不重新拟合**；正在拟合时自动跳过，避免和后台线程抢画布。
顺带把「寿命分布」页标题也带上自定义标题（`Ce6 lifetime - 寿命分布`），
导出 PNG 因此也会是新标题。

## 💬 三、拟合参数改动后会明确提示「需要重新拟合」

网格点数 / τ 范围 / λ / 固定 τ / 拟合方法这些**影响计算**的参数以前在寿命模式下
完全不接线：改了既没提示也没变化，很容易以为程序坏了。现在改动后状态栏提示
「拟合参数已修改：画布还是上一次的结果，点「▶ 开始拟合」重新计算」（启动恢复设置时
不打扰）。外观类参数则即时重画（见上一条），两类行为区分清楚。
