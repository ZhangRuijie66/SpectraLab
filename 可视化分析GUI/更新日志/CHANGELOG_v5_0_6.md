## 🔴 同编号的文件被当平行样，但它们测的不是同一个东西

### 现象

`说明.xlsx` 只给编号（R1/R2/S1…），同编号的多个 CSV 会被自动当成
"同一条件的平行测量"，画成**均值 ± 标准差**。但现实里同编号的文件常常
不是同一种测量。

实测 `示例数据\05-数据比较-浓度梯度` 的 x=10（R1）一组 6 个文件，
其中 **4 个各有一类问题**：

| 文件 | 问题 | 实测数据 |
|---|---|---|
| `R1.csv` | **扫描被截断** | 头部声明 320–800nm / 0.5nm（应 961 点），实际只有 **294 点**，止于 466.5 nm |
| `R1.csv` | **带宽不同** | 3.0 nm，其余 5 个都是 5.0 nm |
| `R1-3.csv` | **激发波长不同** | **650 nm**，其余 5 个都是 520 nm |
| `R1-5.csv` | **峰强取到瑞利散射线** | 全谱最大在 519.0 nm（EX=520，Δ=−1.0 nm），荧光峰在 572 nm |
| `R1-6.csv` | 同上 | 全谱最大在 518.5 nm（Δ=−1.5 nm） |

软件把这 6 个统一算成 `mean = 11706.9 / sd = 6500.9 / **RSD = 55.5%**`，
而它给用户的全部信息只有一句「12 个样品 → 3 个点，误差棒 = 标准差」。

### 为什么现成的离群检验救不了

实测 **Grubbs 检验判定失败**：`G = 1.78 < 临界 1.887`，结论是「不离群」。
原因是离群点自己把 SD 撑大了（分母被污染）——这是单变量离群检验的经典盲区。
而 `R1-3`（EX=650）连判都判不了：它自己就是构成均值的一分子。

**必须靠「测量条件元数据 + 谱形一致性」判断，不能靠数值统计。**

### 修复：新增 `check_comparability()`

`plot_compare.py` 新增，四项独立检查：

| # | 检查 | 判据 | 级别 |
|---|---|---|---|
| ① | **元数据一致性** | 同组文件的 EX 波长 / 激发·发射带宽 / 扫描起止 / 数据间隔不一致 → 以**多数派**为基准列出少数派 | error |
| ② | **数据完整性** | `(End−Start)/Interval + 1` 与实际点数比对，缺 >1% → 报「扫描被截断」 | error |
| ③ | **谱形一致性** | 同组峰位偏离**多数派**超过 ±20 nm | error |
| ④ | **散射污染** | 全谱最大点落在 EX ±15 nm 内 → 报「可能是瑞利线/拉曼带」，并给出它相对荧光区的强度倍数 | warn |

配套 `format_comparability_report()` 把结果排成中文可读文本。

#### 两处实现细节（都是踩过之后改的）

**峰位检查不能拿「组内中位数」当基准。** 第一版这么写，结果 05 数据的
R1 组 **6 个文件全被标成 error**：该组谱形分成两派（570 nm 与 519 nm
各一半），中位数落在两派之间的 544.5 nm，于是两派**都被判偏离**。
真正该标的是少数派，不是所有人。现在改成「先找最密的一簇当参考，
再标偏离该簇的点」，实测只标 3 个（R1-5、R1-6、R1）。

**散射不能只看「距 EX < 15 nm」就一律当瑞利线。** 实测发现两类：
- **瑞利线**（R1-5/R1-6）：压在 EX−1.0/−1.5 nm，强度仅为荧光区的 1.1–1.2 倍；
- **拉曼/散射带**（S3/S4 系列）：在 EX+13.5~15.0 nm、半高宽约 23 nm、
  强度是荧光区的 **5.8–6.7 倍**。这是溶剂拉曼峰，误差影响比瑞利线更大。

现在按距离分两种措辞，并按「成因 + EX 波长」归并同类项——
S3/S4 的 8 个文件合并成 1 条提示（逐个报会把信息页刷满，
反而看不出「这批全中招了」）。

### GUI 接入（只提示、不改数据）

点「数据比较」时，**画图之前**先跑预检：

- 有问题 → 信息页追加明细 + 状态栏提示 + （有 error 时）弹一次说明性警告；
- 无问题 → 状态栏一句「通过可比性检查」。

**故意不拦截**：用户可能明知差异仍要画（比如就想看两批对比），
所以既不阻止、也不自动剔除，只把问题摆出来。

## 🔧 顺带修掉一个静默失效：`data_cache` 不保留真实路径

接入预检时发现：`load_spectra` 把多个文件的数据集拍平成一个列表后，
**文件与数据集的对应关系就丢了**，GUI 只能用 `Path('<emission>')` 占位。

后果：预检想读文件头时**无路径可读**，`read_measurement_header` 对不存在的
路径静默返回全 None，于是①②④三项检查**全部静默失效**——
实测 26 个样品只报出 1 个问题（只剩谱形），修好后报出 **7 个**。

修复：`plot_emission.parse_csv` 给每个数据集补 `_source_path`，
`gui_data._load_emission_files` 用它取代 `<emission>` 占位。
