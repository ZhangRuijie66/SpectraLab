## 🧹 合并图（叠加寿命分布）图例恢复干净：只留样品名

v4.33 曾在叠加图的图例里附上每个样品的**分布振幅 A** 与**窗口内总计数 I**，
每条形如：

```
topic5 - 副本·pure-Trp
    A=0.8566 a.u.（81.8%）  I=8.483e+09 counts
```

实际用起来这个位置不对：叠加图是**看形状对比**用的，样品一多图例就被撑成一大片、
占掉右侧空间；而"逐组分读数"本来就该在单独拟合的「寿命分布」页看。因此
v4.34 把叠加图图例**收回只留样品名**：

```
topic5 - 副本·pure-Trp
topic5_修正为计数·pure-Trp
```

配套调整：

- 图例字号 7 → 8（不再需要为多行条目让路），右侧留白 0.68 → 0.80。
- 删除已无用的 `_overlay_entry_label()` 辅助方法。
- **保留**纵轴那行归一化警告（原来写的是 `⚠ 含归一化输入，I 不可跨样品比`，
  现在图例里没有 I 了，改为指向纵向刻度本身）：
  `⚠ 含归一化输入（各自还原），纵向不可跨样品比`
  —— 归一化数据会被 `preprocess` 各自还原到 1e4 刻度，各曲线绝对刻度不统一，
  纵向数值不可跨样品直接比较，这点与图例是否显示 I 无关，仍需提示。

**组分级的振幅 / 强度占比不受影响**，仍在单独拟合的「寿命分布」页图例里逐组分
给出（v4.33 新增，见 8.8 节）：

```
τ₁ = 0.665 ns, 振幅 6.9%, 强度 1.5%
τ₂ = 2.96 ns, 振幅 100.0%, 强度 98.5%
```
