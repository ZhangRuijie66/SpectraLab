## 🐛 修复：3D 扫描「插值了还是不连续」（B1）

**根因**（对 `20260727-RB-Lu`、`20260728-RB-L8i` 实测）：
原始 EEM 矩阵里有两类伪迹，三次样条插值只会把它们一起放大——

1. **饱和点**：强度卡在仪器上限 50000，占矩阵 11%（8037/70801 点），曲面顶出平板；
2. **周期梳状伪迹**：约 **6.94 nm 周期、3 个通道一簇、峰值饱和**，
   判据是**位置固定在 EM、不随 EX 移动** → 不是样品荧光（荧光带会随 EX 走），
   而是等厚干涉（滤片/窗口 étalon）或光栅鬼线。样条必须穿过这些点，
   于是两侧振铃出**负值**（旧图色标一度到 −20000），视觉上就是"断开的尖刺"。
   **插值密度再高也消不掉**，因为插值只是穿过数据点。

**修法**：`plot_3d_scan.py` 重写为「解析 → 清洗 → 出图」三段，并新增可调的清洗管线：

```
饱和掩膜 → 沿 EM 线性补全 → 周期梳状伪迹处理 → 中值去残余窄线 → 高斯平滑 → 三次样条加密
```

- 梳状伪迹三种处理：`minima`（默认，只保留条纹谷值通道再插值重建）、
  `divide`（按乘性条纹除法）、`rows`（污染行整体替换），可关闭；
- 色标默认取**稳健分位**（1%–99.5%），避免被伪迹独占；
- 可选对数色标；大网格自动抽稀渲染，避免几十万四边形糊成噪点；
- 顺带修掉两处旧问题：**解析时空单元格导致列左移**（`continue` → 按位置记 NaN）、
  **缺 `_safe_print`** 在 GBK 终端打印 emoji 直接崩溃（`UnicodeEncodeError`）。

**效果**（RBLu 1）：清洗后强度范围 1008–12936（原 1003–50000），**负值 0 个**，
等高线上的水平条纹消失，`EM+EX≈1370 nm` 的斜带与真实发射带清晰可辨。
