# 🆕 2.2 版本更新说明

**版本**：v2.2
**日期**：2026-08-26

---

## 🎉 版本升级说明

本版本重点：**隐藏启动时的 cmd 窗口**，让程序双击启动时更干净。

**窗口标题** 已更新为：**"光谱可视化分析工具 v2.2"**

---

## ✨ 主要改动

### 🖥️ 无窗口启动
- 新增 **launch_hidden.py**：无控制台窗口的启动入口（不含 print，兼容 pythonw）
- 新增 **光谱可视化分析工具.lnk**（快捷方式）：双击后**不显示黑色 cmd 窗口**，直接用 `pythonw.exe` 启动 GUI
- 更新 **run_gui.bat**：改用 `start "" pythonw launch_hidden.py`，尽量隐藏窗口

### ⚠️ 说明：VBS 方案不可用
- 原计划用 VBS 隐藏窗口，但你的系统 **wscript/cscript 被禁用**（弹窗"加载设置失败（拒绝访问。）"）
- 因此改用**快捷方式 + pythonw** 方案，不依赖 wscript，更可靠

---

## 🚀 启动方式（v2.2）

### 主要方式：双击快捷方式（无窗口）
```
双击：光谱可视化分析工具.lnk
```
- 直接以 `pythonw.exe` 启动，**不显示 cmd 窗口**
- 桌面图标方式也推荐用此快捷方式

### 备选：双击 bat
```
双击：run_gui.bat
```
- 改用 `pythonw` 启动，窗口基本不显示
