## ✨ 新增

### B4 导出格式可选（PNG / PDF / SVG）

- 参数面板「分辨率 (DPI)」下方新增 **「导出格式」** 下拉框：
  `PNG (位图)` / `PDF (矢量)` / `SVG (矢量)` / `PNG + PDF` / `PNG + SVG` /
  `全部 (PNG+PDF+SVG)`。
- **寿命模式**的「导出全部图片」原来硬编码只出 PNG，现在按所选格式导出
  拟合图 + 寿命分布图（矢量图便于投稿排版）。
- 「导出图片」的默认文件名扩展名跟随所选格式（文件对话框里仍可临时改）。

### C7 速率网格范围 k_min–k_max 可在 GUI 调

- 荧光寿命选项组新增 **「速率网格范围 k (1/ns)」** 两个输入框（默认 0.01–100，
  即 τ = 100 ns–10 ps）。要拟合更长寿命（μs 级）把 k_min 调小即可。
- 实际使用的 k 网格、对应 τ 范围与点数写入结果 `info`，信息页可见。

### C2 本底改用中位数

- `preprocess` 的 `decay_background` 由**均值改为中位数**。数字化谱图的本底
  尖峰会把均值抬高（实测 Fig5_0M 前 11 通道均值 52.7、真实本底仅 ~10），
  中位数更接近真实本底，避免 `fit_end` 判据被噪声拽长。
- 均值同时记入 `info['decay_background_mean']` 便于回溯；
  `info['decay_background_stat'] = 'median'`。
- 回归验证：esipt Decay2 拟合结果 χ²R = 1.014、双寿命 0.87/6.22 ns，
  与改前一致（该数据本底干净，中位数≈均值）。

### C4 + C5 拟合诊断页 + 拟合质量报告

- 新增 **「拟合诊断」标签页**（仅寿命模式显示）：
  - 上：原始 IRF、平移后 IRF、衰减数据、拟合曲线（同一标度），
    并用绿色虚线标出**拟合起点 / 终点**，标注 qshift（ch 与 ns）；
  - 下：**残差自相关**（滞后 0–24 通道）与 95% 置信带 ±1.96/√N，
    标题直接给出超出置信带的滞后点个数（越多说明残差越有结构）。
- 信息页新增 **「拟合质量」** 段：拟合点数 M、χ²R 与 χ²、
  **Durbin–Watson**（<1.5 提示残差正相关/模型不足）、残差均值/标准差、
  残差自相关 lag1 与置信带、皮尔逊残差 |r|>3 的通道占比、实际速率网格。
- 修正口径标注：`info['chi_sqr']` 本来就是 χ²/M（分母是点数 M，不是自由度 ν），
  报告里明确写出，避免与 χ² 混淆。

### C6 固定寿命分量

- 荧光寿命选项组新增 **「固定寿命分量 τ (ns，逗号分隔)」** 输入框
  （支持中文逗号，非法输入静默忽略）。填了以后：
  - 每个 τ 作为一条**不受熵约束**的基函数 `exp(-t/τ)⊛IRF` 加入模型，
    幅度自动求解（用于扣除参照染料寿命、IRF 拖尾等已知分量）；
  - **同时把速率网格上该 τ 附近 ±0.15 个数量级锁定为 0**——否则熵分布
    会自己把这段吃掉、固定分量幅度被压到 0（首版就是这样，固定 6.2 ns
    幅度解出 0.0；加锁定后解出 3000 counts，分布里 6.2 ns 段消失）。
- 实测（esipt Decay2，固定 τ=6.2 ns）：χ²R = 1.025（未固定时 1.014），
  固定分量幅度 3000 counts，剩余分布峰位 0.76/4.36/9.11 ns。

### C1 + C8 并行拟合全部 + 寿命分布叠加

- `plot_lifetime` 新增模块级 **`fit_many(datasets, max_workers=…, fit_kwargs=…)`**：
  用 `ProcessPoolExecutor` 多进程并行拟合（worker 为模块级函数，Windows spawn
  可 pickle）；**并行不可用时自动退回串行**，不会让整批失败。
- 荧光寿命选项组新增 **「📊 叠加寿命分布（并行拟合全部）」** 按钮：
  并行拟合当前文件夹的全部样品，在「寿命分布」页把各样品分布**按自身最大值
  归一**叠在一张 log-τ 图上（图例在轴外右侧），并自动切到该页。
- 说明：MEM 单文件 1–2 分钟，多文件并行是主要收益；SESM 小网格单文件只要
  几秒时，多进程启动开销可能反而更慢（实测 3 文件 SESM/101 点 0.58×），
  这类小任务建议直接逐个跑。
