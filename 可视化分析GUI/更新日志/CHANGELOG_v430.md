## 一、新增第三套主题：高对比（打印友好）

主题从"浅色 / 深色"两套变三套，新的一套两个目标同时满足：

| 目标 | 做法 |
|---|---|
| **屏幕可读性** | 正文、次级文字、五个语义色对底色对比度**全部 ≥ 7:1**（WCAG **AAA** 级），投影、明亮环境、视力不佳时都看得清 |
| **打印友好** | 纯白底（`#ffffff`）+ 纯黑描边与文字（`#000000`）+ 不用大面积低对比灰底；黑白激光打印后靠**边框和字重**仍能分辨层级 |

关键取值（都按 WCAG 相对亮度公式核算，回归测试里逐项实测）：

| 令牌 | 值 | 对白底对比度 |
|---|---|---|
| `TEXT` | `#000000` | 21.0:1 |
| `TEXT_SOFT` | `#1a1a1a` | 17.4:1 |
| `MUTED` | `#4d4d4d` | 8.4:1 |
| `ACCENT` | `#0033cc` | 8.9:1 |
| `SUCCESS` | `#006400` | 7.4:1 |
| `VIOLET` | `#5b00b3` | 10.0:1 |
| `ORANGE` | `#8f3800` | 7.7:1 |
| `CYAN` | `#00556b` | 8.4:1 |
| `DANGER` | `#a80000` | 7.9:1 |
| `BORDER` | `#000000` | 21.0:1（卡片/输入框描边） |

绘图区也跟着换：白底、**纯黑坐标轴**、中性灰网格（打印后仍是浅参考线）、
选中态改成"深蓝实心 + 白字"（8.9:1），tooltip 用黑底白字。

## 二、主题按钮改成三态循环

- 点「🌓」按钮（或 `Ctrl+T`）按 **浅色 → 深色 → 高对比 → 浅色** 循环；
- 按钮图标显示的是**点一下会切到的那套主题**的象征物：
  浅色→月亮 / 深色→对比度圆 / 高对比→太阳；
- tooltip 与状态栏都会写明"当前是什么、再点一次切到什么"；
- 新增图标 `contrast`（半明半暗的圆），图标集 24 → **25 个名字**。

## 三、design token 收敛

把散在各文件里的写死颜色收回到色板（改一处不会再漏另一处）：

| 位置 | 原来 | 现在 |
|---|---|---|
| `gui_launcher.MODES` 四个模块卡片主色 | 写死 `#2563EB` `#16A34A` `#7C3AED` `#0891B2` | 引用 `ACCENT` / `SUCCESS` / `VIOLET` / `CYAN` |
| `gui_components` 下拉弹窗选中项文字色 | 写死 `#ffffff` | 引用色板的 `CARD`（跟着主题走） |
| `gui_components` 画布占位提示文字 | 写死 `#64748b` | 引用浅色主题的 `MUTED` |
| `gui_plot` 导出「白底图」的描边/文字/网格色 | 写死 `white` / `#cbd5e1` / `#1e293b` | 引用浅色主题的绘图令牌（它就是"白底出版图"那套配色） |

**科学曲线配色（Tol 色板：`#66ccee`/`#ccbb44`/`#ee6677` 等）刻意保持不动**——
它们是数据区分色，跟界面主题无关，跟着主题变反而会让同一批图在不同主题下对不上。

## 五、备注

- **什么时候用高对比**：投影/组会（白底黑字最清楚）、需要打印附录图、
  或者屏幕反光严重时。日常调参还是用浅色/深色更柔和。
- 三套主题**都记在会话里**，下次启动沿用上次那套。
- 加主题这件事本身以后也简单：往 `THEMES` 加一套（键要和原来完全一致）、
  在 `THEME_ORDER` 里排上、`生成图标.py` 的 `THEMES` 加一行描边色再跑一次脚本即可；
  回归测试会替你检查"键是否齐全、对比度是否达标"。
