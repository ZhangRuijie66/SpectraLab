## 一、三栏可折叠 + 宽度记忆（治「想看图就得跟三栏抢地方」）

### 旧实现的问题

「目录树 | 数据 | 参数 | 画布」四栏固定并排，前两栏各 200/210px、参数栏 285px，
在默认窗口（1368×783）里画布只剩 **597px**——看一张带图例的光谱图很局促，
想临时腾地方只能手动拖分隔条，下次启动又回原样。

### 新实现

最左侧新增一条 **34px 的「栏开关条」**（竖排三个按钮：目 / 数 / 参），
点一下折叠对应栏目，再点展开：

| 折叠的栏 | 画布宽度（默认窗口 1368×783 实测） |
|---|---|
| （都不折叠） | 597 px |
| 目录树 | 801 px |
| 目录树 + 数据 | **1015 px** |
| 目录树 + 数据 + 参数 | **1304 px** |

**为什么开关条放在 splitter 外面**：折叠用 `setVisible(False)` 实现（Qt 的
splitter 会跳过隐藏子控件，剩下的栏自动重排）。代价是栏内**所有**控件一起消失——
折叠按钮如果放在栏里，折起来就再也点不回去了。所以入口固定在栏外，
且不受任何栏的显隐影响。

**宽度记忆**：拖动分隔条后的各栏宽度 + 折叠状态一起写进 QSettings
（`ui/panel_widths` / `ui/panel_hidden`），下次启动原样恢复；
越界值（<80px 或 >1200px）直接忽略，坏设置不会把界面搞乱。
展开时回到折叠前的宽度（以该栏最小宽度兜底）。

派生效果：状态栏会给出「数据栏已折叠」反馈；`Ctrl+F` 若数据栏是折叠状态，
会先自动展开再聚焦搜索框。

## 二、文件列表：搜索 + 全选（治「几十个样品靠滚动找」）

数据栏顶部新增：

- **搜索框**（占位符「搜索文件名…」，带清除按钮）：按文件名过滤，不区分大小写；
  计数标签同步变成「已加载 7 个（显示 4）」；
- **「全选 / 全不选」按钮**：文字随状态自动切换，**只作用于当前筛选结果**。

两条关键设计（都有回归测试守着）：

1. **过滤只影响显示，不动勾选状态**——用 `QListWidgetItem.setHidden()` 实现，
   所以「筛选出几个 → 全选 → 清空搜索词」不会把别的勾选弄丢；
2. **全选按筛选结果走**：一次加载几十个样品、只想画其中一组时，
   搜关键词 → 全选，两步就能圈定，不用一个个点。

一次加载几十个样品时的实测：搜索 `1000` 把 7 个样品过滤成 4 个，
全选后只勾这 4 个；清空搜索词，勾选数仍是 4。

另加 **Ctrl+F** 跳到搜索框（数据栏折叠时自动展开）。

## 三、积分结果改表格（治「像调试输出」）

原来积分结果写在一块只读 `QPlainTextEdit` 里，等宽文本、不能排序、只能整块复制。
现在改成 `QTableWidget`：

- 三列：**样品 / 区间 (nm) / 积分值**（区间与表头一致，不再每行重复 "450nm-550nm"）；
- **点表头排序**：样品列按文本、积分值列按**数值**——`9` 不会再排到 `100` 后面
  （`QTableWidgetItem` 默认比较字符串，为此单独做了 `NumericTableItem`，
  并且填充时先关排序，否则逐行写入会让行号乱跳）；
- **框选 + Ctrl+C** 复制选中行；「📋 复制结果」复制整张表（制表符分隔，
  带表头，可直接粘进 Excel/Origin）；
- 新增 **「⤓ CSV」** 导出按钮：写 `积分结果_<起>-<止>nm.csv`，
  编码 **UTF-8 BOM**，Excel 双击打开中文不乱码；
- 与范围相关的提示（无效范围、所选范围无数据重叠）原来写在文本框正文里，
  现在收进右侧计数标签。
