# 🆕 4.0 版本更新说明

**版本**：v4.0
**日期**：2026-08-29

---

## ✨ 新增：入口界面（模块选择）

- 新增 `gui_launcher.py`：启动时先弹出「请选择要使用的模块」对话框，
  三个大按钮（📊 吸收光谱 / 📈 发射光谱 / ⏱ 荧光寿命，各带一句话说明），
  选择后以 `AbsorptionGUI(initial_mode=...)` 进入对应模式的主窗口；
- 关闭对话框（Esc / 右上角×）则退出程序；
- 两个启动入口（`absorption_gui.main`、`start_gui.py`）都接入入口界面；
- 主窗口左上角的下拉框仍可随时切换模式。

## 🛠 改进：寿命拟合画布重新布局

- **「预览」标签页**恢复为拟合曲线（log 轴）+ 残差的上下两栏，
  `sharex` 横轴严格对齐（v3.1 的右下角分布图移出）；
- **寿命分布独立成图**：右侧新增第三个标签页「寿命分布」（独立 MplCanvas
  + 工具栏），拟合完成后自动刷新，单独一张图（对数 τ 轴 + 高斯分量 + 图例）。

## ✨ 改进：导出统一为两张图

寿命模式下「导出图片」与「导出全部图片」统一走 `_export_lifetime_plots`：
一次导出
1. `{文件名}_lifetime_fit.png` —— 拟合曲线+残差合并图；
2. `{文件名}_lifetime_peaks.png` —— 寿命分布图；
3. `{文件名}_fit_result.json` —— 完整拟合结果。

## ✨ 新增：「⏱ 开始拟合」按钮

「荧光寿命拟合」组内部最下方新增绿色拟合按钮（等效实时预览的显式触发），
组内提示文字同步改为指向该按钮。
