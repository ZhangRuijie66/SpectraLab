## 🪟 门户入口无法最小化（用户反馈）

- **现象**：入口门户（选择模块的那一屏）标题栏只有「关闭」和一个「？」，
  **没有最小化按钮**，用户没法把它收进任务栏。
- **根因**：`ModuleLauncher` 继承 `QDialog`，而 QDialog 的默认 windowFlags 是
  `0x08013003`，**不含 `WindowMinimizeButtonHint`（0x20000）**——
  Qt 从设计上就不给对话框最小化按钮，此前也没人显式补过。
- **修复**：显式补上 `WindowMinimizeButtonHint` + `WindowCloseButtonHint`
  （「？」保留，拦截它显示帮助）。实测 flags `0x08013003 → 0x0801F003`，
  最小化/还原均正常。
- **顺带**：不加最大化按钮。门户是固定版式的选择页（4 张定宽卡片），
  最大化后卡片被拉到屏幕宽度、文字挤在左侧一大片留白，反而更难用
  （截图实测 2880px 宽下卡片横贯整屏）。同时 `setMaximumSize(1180, 860)`
  兜住"被外部强行最大化"的情况，保证版式始终合理。

## 🔍 部分文件解析失败被静默丢弃（P1，可信度问题）

- **现象**：一批 5 个文件，成功 3 个、失败 2 个时，状态栏只写
  「成功加载 3 个文件」，**失败明细 `errors` 直接被丢弃**（代码里只有
  `loaded_count == 0` 才提示）。用户以为这一批就只有 3 个样品，拿去做后续分析。
- **修复**：
  - 加载时把 `errors` 存进 `_load_errors`；
  - 计数标签变成「已加载 3 个文件，**2 个失败**」，**悬停即看明细**
    （前 8 条失败文件+原因 + 日志路径）；
  - 状态栏同时提示「另有 2 个解析失败（把鼠标移到「已加载 N 个」上看明细）」；
  - 明细写进日志（`logging.warning`）。
- 实测：混合文件夹（3 正常 + 2 坏）→ 标签「已加载 3 个文件，2 个失败」、
  悬停列出两条原因；全正常时不误报（标签无"失败"、tooltip 为空）。

## ⌨️ 入口门户键盘不可达（P1，可访问性）

- **现象**：4 张模块卡片全是 `QFrame` 且未设 `focusPolicy`（= `Qt.NoFocus`），
  整个对话框里连一个 `QPushButton` 都没有 —— 程序**第一屏**完全无法用键盘操作：
  Tab 没有焦点框、Enter 没反应、方向键也选不了，只能用鼠标点。
- **修复**：
  - 卡片 `setFocusPolicy(Qt.StrongFocus)`；
  - `keyPressEvent`：Enter / Enter（小键盘）/ Space 激活；↑↓ 在卡片间移动焦点；
  - `focusInEvent`/`focusOutEvent` → 切一个 `focused` QSS 属性，画 2px 主色焦点框；
  - 首帧把焦点给第一张卡片（打开即可直接回车进入）；
  - 底部提示补「键盘：↑↓ 选择，Enter 进入」。
- 实测：4 张卡片 `focusPolicy=11`（StrongFocus）；↓ 四次经过 `[0,1,2,3]`；
  Enter 激活 `absorption`、空格激活 `emission`。

## ⏎ 帮助窗口里按 Enter 会静默复制全部正文（P1）

- **现象**：帮助窗口里，用户在正文区按 Enter（读帮助时的下意识动作），
  会**静默把全部正文刷进剪贴板**，覆盖掉用户自己复制的内容，且无任何提示。
- **根因**：`QDialog` 里第一个 `QPushButton`（这里是「复制全部」）会被 Qt 当成
  默认按钮，Enter 即触发。
- **修复**：`copy_btn` / `log_btn` 显式 `setAutoDefault(False)` + `setDefault(False)`；
  「关闭」设为默认按钮（Enter = 关闭，符合直觉）。
- 实测：正文区按 Enter 剪贴板内容不变（哨兵值原样）；点「复制全部」仍正常复制；
  `close_btn.isDefault() == True`。

## 📜 参数栏常驻滚动条（P1，布局密度）

- **现象**：参数栏内容总高远超可视高度，审计实测**四档分辨率全部溢出**
  （2560×1440 下仍需滚 0.7 屏，1440×852 下要滚 2 屏以上），竖直滚动条常驻。
- **修复**：新增 `CollapsibleGroup`（可折叠分组框，点标题收起/展开），
  把**低频**组默认收起：
  - 「峰检测参数」：展开 186px → 收起 **38px**（省 148px）
  - 「光谱减法」：同样省 148px
  - 「显示范围」保持展开（调图高频）
- 实现要点：内容放进内部容器，折叠只 `setVisible(False)`，**不重建任何控件**，
  因此既有控件引用、数值、信号全部不受影响；`setLayout()` 做了兼容
  （把外部布局里的项迁进内层容器），所以老代码按 `QGroupBox` 写法调用也正常。
- 顺带修一个视觉问题：`QGroupBox::indicator` 此前没有 QSS 规则，走 Qt 默认绘制，
  在深色主题下是个**黑方块**。已与 `QCheckBox` 共用同一套指示器样式。
- 实测：折叠后可见分组高度合计 771px（修复前参数区内容约 1720px）；
  收起状态下 `peak_height_spin` 仍可读写、`_collect_plot_params` 取值正确。
