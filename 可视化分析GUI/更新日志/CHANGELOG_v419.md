# 🔧 4.19 版本更新说明

**版本**：v4.19
**日期**：2026-09-09

---

## 🐛 修复（用户 v4.18 实测反馈）

### 1. 文件夹路径显示不全

- 「文件夹: …」标签字号 15px → **12px**（去掉加粗）。
- 长路径**自动缩成「…\\父目录\\末级目录」**，完整路径放进**鼠标悬停提示**
  （`setToolTip`）。例如
  `D:\北大\光谱工具\示例数据\测试数据\20260727-RB-Lu`
  → 显示 `文件夹: …\光谱\20260727-RB-Lu`。
- 会话恢复时同样走短路径显示。

### 2. 「3D 扫描 (EEM) 选项」组太宽、默认宽度下显示不全

- 参数栏最小宽度 300 → **340**，默认宽度 320 → **360**。
- `SliderSpin`（滑块+数值框）数值框最小宽度压到 **74px**、滑块 **46px**，
  不再把整组控件顶出可视区。
- 缩短控件文案，减少组合框的最小宽度需求：
  - 梳状处理：`只保留谷值通道（推荐）` → `只保留谷值通道`、
    `污染通道整行替换` → `污染整行替换`
  - 出版图预设：`无（默认 10×6 in）` → `无（默认）` 等
  - 3D 提示文字去掉硬换行、压缩措辞
- 验收：3D 选项组实际宽 335px / sizeHint 337px（基本贴合），
  组合框箭头、滑块、数值框全部可见，无横向截断
  （截图 `plots\_diag3d\ui_scan3d_group.png`）。

### 3. 「自动拟合 λ」改为默认勾选

- 荧光寿命选项组的「自动拟合 λ（推荐）」**默认勾选**，且 λ 输入框随之禁用。
- 关键点：**不再从上个会话恢复这一项**——否则旧的 `False` 会覆盖默认值
  （首版就是这么翻车的：代码改成默认 True，但 QSettings 里存着 False，
  启动后仍是未勾选）。现在每次启动都强制勾选，需要手动改回就在本次会话里取消。
