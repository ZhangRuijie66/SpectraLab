# 🆕 2.4 版本更新说明

## ✨ 修复：说明.xlsx 读取功能纳入打包

此前虽然已在源码中加入「读取 说明.xlsx 并写入图例」的功能，但**打包时把
`openpyxl` 排除掉了**——而 pandas 读取 `.xlsx` 默认正是使用 `openpyxl` 引擎。

由于打包后的 exe 缺少 `openpyxl`，`pd.read_excel` 在运行时静默失败，导致：
- 打包版里读取文件夹时「说明.xlsx」信息**不会**写入图例；
- 状态栏也提示「说明.xlsx 未找到或读取失败」。

**本次修复**：
1. 从 `打包便携版.ps1` 的排除列表 `$excl` 中**移除 `openpyxl`**；
2. 新增 `--hidden-import openpyxl`，确保其依赖一并打包进 exe；
3. 重新打包，使打包版与源码版行为一致（能正常读取 说明.xlsx 并增强图例）。

### 顺带修正
- `gui_config.py` 中 `DEFAULT_WORKSPACE` 路径原先被写成双反斜杠（生成器产物），
  已改回正确的单反斜杠（`D:\北大\QLS Lab\...`）。
