## 一、全局拟合（G3）

同一个体系的多次测量/多波长衰减/系列样品，逐个独立拟合会因噪声让 τ 抖动。
本版新增两个全局模型（`plot_lifetime`）：

### 1. `fit_global()` —— 共享速率分布

模型 `y_d(t) = (A_d @ p) · decay_max_d · s_d + bg_d`：所有数据集共享同一份
速率分布 `p`，各自只有幅度 `s_d`。适合**同一样品的重复测量 / 多检测窗**。

- `p` 用 **softmax 参数化**（Σp ≡ 1，无需等式约束）；
- 优化器用 **L-BFGS-B + 解析梯度**（实测 SLSQP 在这类问题上会停在
  "报告成功但完全没动"的点：cost 522.7 不变；L-BFGS-B 收敛到 2.19）；
- 多起点（均匀分布 + 数据量最大的数据集单独拟合出的分布）；
- 可选 `auto_lambda` λ 扫描。

实测（合成双指数 2.5/8.0 ns 两个数据集）：Σχ²R = 2.13，τ = 2.468/7.927 ns，
占比 41.7%/58.3%（真值 42.2%/57.8%）。

### 2. `fit_global_discrete()` —— 共享寿命 τ、各样品独立幅度

模型：所有数据集共享 `n_comp` 个寿命 τ_i，每个数据集自己解幅度 a_{d,i}
（给定 τ 时是线性问题，用 NNLS 精确求解），τ 用 Nelder-Mead 优化。
适合**滴定/系列样品**（如 FRET A0→A24：供体寿命随受体浓度变化）。

实测（7 份 FRET 数据，n_comp=3）：共享 τ = 0.735/2.018/3.521 ns，
Σχ²R = 17.8，各样品给出独立的占比 —— 直接可做 FRET 效率曲线。

> ⚠️ 两者都做了**关键修正**：基函数必须"先卷积 IRF、后按 qshift 做 PCHIP 平移"
> （与 `MEMFitter` 一致）。反过来先平移 IRF 再卷积，在 qshift 较大时会产生
> 亚通道系统偏差，同一数据 χ²R 从 3.7 恶化到 285。

## 二、3D 扫描：散射剥离与定量校正（G4）

### 1. 瑞利/拉曼散射带剔除

`prepare_grid(remove_scatter=True)`（**默认关闭**，CLI `--remove-scatter`）：

- 瑞利带：|EM − EX| ≤ `rayleigh_width`（默认 ±10 nm）；
- 拉曼带：EM = 1/(1/EX − Δν·1e-7)，Δν 默认 3350 cm⁻¹（水的 O–H 伸缩），
  半宽 `raman_width` 默认 ±15 nm；
- 命中点置 NaN 后**沿 EM 内插补全**（不外推），并记录
  `scatter_removed / scatter_rayleigh / scatter_raman`；
- 安全阀：掩膜覆盖 >50% 数据时自动跳过并告警（宽度设错时不会毁数据）。

实测（合成 EEM）：对角线区均值 982 → 330，**非散射区逐点零改动**。

### 2. 空白（溶剂）扣除

`prepare_grid(blank=<空白数据集>)`：先做 `Z − Z_blank`，要求 EX/EM 网格一致，
不一致时明确报错（不再静默错位相减）。

### 3. 内滤效应校正

新增 `inner_filter_correction(data, a_ex, a_em)`：
`F_corr = F_obs · 10^((A_ex + A_em)/2)`，长度不匹配或含 NaN 会报错。

## 三、跨样品汇总图（G5）

`plot_summary(results, save_dir, x=None, xlabel=...)`：三联图（共享横轴）

1. 各寿命分量 τ_i（对数纵轴）；
2. 各分量强度占比 α_i；
3. χ²R（对数纵轴，虚线标 1）。

GUI 寿命模式新增按钮 **「📈 跨样品汇总图」**：并行拟合当前文件夹全部文件后
直接出图，不用手动导 Excel。

## 四、一键 PDF 报告（G6）

`export_report_pdf(results, save_dir)`：多页 PDF

- 第 1 页：汇总表（样品/方法/χ²R/拟合区间/各分量 τ 与 α）+ χ²R 柱状图；
- 之后每个样品一页：衰减 + 拟合（对数纵轴）+ 平移后 IRF + 寿命分布
  （标注各分量 τ 与占比）+ 残差统计。

GUI 寿命模式新增按钮 **「📄 导出 PDF 报告」**。
