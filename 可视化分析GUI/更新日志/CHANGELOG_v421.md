## 🔴 一、会让结论出错的（拟合可信度）

### 1. 拟合器会静默给出未收敛的解 —— 已修

- **实测证据**：合成真值数据（τ=2.5/8.0 ns 双指数 + 泊松噪声）上，同一基函数下
  旧实现给 **χ²R≈134**、峰 2.0/4.11/10.97 ns；而 `scipy.optimize.nnls` 的精确解
  χ²R≈**0.91**、τ=2.50/7.99 ns。SLSQP 还报告 `status=0 / success=True`。
- **修法**：① 粗估与每一轮迭代都用 **NNLS 精确解**热启动；② `_chi2` 与熵项提供
  **解析梯度**（不再让 SLSQP 对 201 维做有限差分）；③ 每轮记录
  `res.success/status/nit`，未收敛写入 `quality_notes` 并告警。
- 修复后同一数据 χ²R=0.894、τ=2.50/7.99 ns、占比 42.5%/57.5%（真值 42.2%/57.8%）。

### 2. χ² 口径统一并显式标注

- `info` 新增 `chi2_type='neyman_obs_denominator_over_M'` 与 `chi_sqr_pearson`
  （同一数据的 Pearson 口径），GUI 信息页同时显示两者；
- 观测值下限从 0.1 提到 1.0（旧口径下低计数点会以 1/0.1 的权重单点主导 χ²R）；
- GUI 的「皮尔逊残差 |r|>3 占比」改用**模块自身的残差**，不再另算一套口径。

### 3. SESM 的 λ 现在真正生效

旧实现把平滑权重写死为 `1e-1`，`lambda_coeff` 对 SESM 完全无效（无噪声单指数
χ²R=130.6）。现在权重 = `λ · Σ(Δ²p)² / n_rates`，并记录 `smooth_weight_used`。

### 4. 退化输入不再静默给结果

长度不一致 / NaN / 时间轴非递增 / IRF 全 0 / 平坦无信号 / `n_rates<3` /
`k_min≥k_max` / 未知方法 / 点数少于分量数 —— 全部抛 `ValueError` 或
`RuntimeError`，不再出现 `χ²R=nan` 却报告"100% 单分量"。

### 5. 新增边界堆积与未归属质量诊断

`intensity_share_grid_edges`（>5% 告警）、`intensity_share_fastest_decade`、
`intensity_share_slowest_decade`、`intensity_share_unassigned`。
实测 auto λ 下分布有 57.7% 的**幅度**落在 τ≤0.05 ns 的网格边界，
现在会被明确提示（可改 k_min 复算区分真实快分量与边界伪影）。

### 6. 分量个数不再随 n_rates 漂移

判峰改为相对峰高 2% + log-k 空间 0.08 dex 间距（旧：绝对阈值 0.005 + 点数距离 5，
同一份数据在 101/201/401 点下给出 2/3/4 个分量）。
新增 `peaks_found` / `peaks_dropped` / `peaks_dropped_low_share`（<0.5% 的噪声分量被丢弃）。

### 7. 3D 清洗不再造假数据

- 整条 EX 通道缺测不再填 0（会造出人造暗带），改为沿 EX 插值，插不了保留 NaN；
- 样条加密后的负值显式截断并记录 `neg_after_spline`；
- `Z_orig` 改为拷贝（旧为别名）；
- EX 轴也排序 + 重复波长合并（旧只处理 EM，EX 递减时加密静默失败）；
- `_remove_comb_rows` 的 `harmonics` 参数真正生效；
- 新增校正后残余条纹强度比 `comb_residual`（>0.30 提示换模式）。

### 8. 解析层修正

- 发射模块 Spectracle CSV 改为**按行对齐**去 NaN（旧逐列去 NaN 后按 min_len 截断，
  一个空格子就让波长与强度整体错位）；
- 吸收 `calculate_absorption_coefficient` 的浓度改为**必填**（旧默认 1 mol/L，
  等于把 A/l 冒充成 ε）；
- 寿命模块 GBK/BOM 编码回退（旧 pandas 分支固定 utf-8 直接抛错）、
  第 4 列以上有文本备注时不再整表清空、xlsx 按 (时间,样品,IRF) 三元组逐样品对齐；
- 吸收光谱的"自动对数轴"只在全正且动态范围 >100 时启用（旧逻辑对含负值/零基线的
  吸光度会静默切对数并裁掉负值区）。

## 🎨 二、主题收口（v4.20 的遗留）

1. **深色下下拉框弹出列表不再是白板**：`ComboItemDelegate` 取色改为随主题
   （模块级色表 + `set_combo_palette()`，切换主题立即生效，无需重建 delegate）。
2. **切换主题不再清空寿命拟合画布**：旧实现无条件 `update_plot()`，寿命模式
   非 explicit 分支会 `clear_fig()` 画提示文字，刚拟合好的图从画面消失；
   现在有结果时只做纯渲染。
3. **副画布既有文字换色**：标题/轴标签/刻度/图例/网格线全部随主题更新
   （旧只改 axes 属性，切到深色后文字停在 #1e293b，对 #0f172a 仅 1.49:1）。
4. **诊断页硬编码颜色主题化**（ACF 柱 #7C3AED 对深色底仅 2.75:1）。
5. **入口界面（返回模块选择）跟随主题**，不再是写死浅色。
6. **主画布占位文字登记进 `_placeholder_texts`**。
7. **新增「导出用白底」开关（默认勾选）**：深色主题下导出投稿图自动白底深字，
   界面外观不受影响。
8. 导航工具栏图标用 `QGraphicsColorizeEffect` 染成主题前景色（旧图标对比度仅 2.5:1）。

## 📦 三、导出与交付：不再静默出错

   磁盘上只剩 1 张；现在自动补样品名并去重（`_2/_3`）。
2. **3D 模式「导出全部图片」不再写 0 个文件却弹「成功」**：新增
   `_export_scan3d_plots()`（当前绘图类型 + 清洗统计 json）。

4. **失败计数与明细**：弹窗显示「成功 N 张，失败 M 张」及前 5 条失败原因。

## ⚡ 四、响应性与健壮性

1. 加载数据加等待光标 + 确定进度 + `processEvents` + 重入保护，不再"未响应"；
2. 目录树**双击才加载**（单击只展开），最近文件夹只在真正加载到文件时写入；
3. 拟合中切模式/换文件夹会先询问并中止，不再 `KeyError` 丢结果；
4. 后台线程不再直接读 Qt 控件（主线程先取快照），`MplCanvas.busy` 期间跳过 resize 重绘；
5. 寿命拟合新增**进度框 + 取消按钮**（`progress_cb` / `cancel_cb` / `FitCancelled`），
   取消后保留上一次结果；
6. 新增 `gui_log.py`：日志落盘到 `%LOCALAPPDATA%\QLSLab\logs\gui.log`
   （打包后 stdout 为 devnull，旧实现 84 处 `except: print()` 等于没有提示），
   未捕获异常写日志并弹窗，帮助菜单加「打开日志文件夹」；
7. 拟合中关窗会询问；
8. 入口加 `multiprocessing.freeze_support()`（`fit_many` 用 ProcessPoolExecutor，
   onefile 打包下缺它会让子进程重跑主程序），并行失败自动退回串行。
