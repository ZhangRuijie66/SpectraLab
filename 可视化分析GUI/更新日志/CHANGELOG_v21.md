## ✨ 新增功能

### 📏 显示范围（波长上/下限）

在参数面板新增 **"显示范围 (nm)"** 设置，用于控制图表的 X 轴（波长）范围：

- **波长下限**：设置 X 轴最小值（加载数据后自动设为数据的实际最小波长）
- **波长上限**：设置 X 轴最大值（加载数据后自动设为数据的实际最大波长）

> 显示范围**直接可调**，无勾选开关、无范围类型选择。加载数据后自动将上下限设为该批次数据的实际波长范围，之后可自由调整。

效果：
- 调整上/下限后，绘图将**只显示该波长区间**的数据
- **Y 轴自动随区间内数据缩放**：只根据所选波长区间内的数据点重新调整 Y 轴范围（加 10% 边距），不再显示全范围
- 适用于**吸收光谱**和**发射光谱**
- 合并图、单独图都支持
- 实时预览自动生效
- **默认值自动设为数据范围**：每次加载数据后，波长上下限自动填充为该批次数据的实际最小/最大波长

## 📊 应用范围

| 配置 | 是否支持 | 说明 |
|------|---------|------|
| 启用显示范围 | ✅ | 勾选即生效 |
| 吸收光谱 | ✅ | 合并图/单独图 |
| 发射光谱 | ✅ | 合并图/单独图 |
| 波长下限/上限 | ✅ | 单独设置 |

---

## 🚀 使用方法

1. 加载数据后，**波长下限/上限自动设为数据的实际范围**（默认即全范围）
2. 需要查看局部时，直接**调整波长下限/上限**（如 300–600 nm）
3. 图表自动更新，只显示所选波长区间，Y 轴同步缩放

**示例**：想只看 300-600 nm 的吸收带，把波长下限设为 300、上限设为 600 即可。

## 🔧 技术点

- 新增 `_get_xlim()` 方法，根据启用状态和上下限生成 X 轴范围
- 应用 `ax.set_xlim()` 并锁定 `set_autoscale_on(False)`，避免固定范围被重新缩放
- 四个绘图方法（吸收/发射 × 合并/单独）都已支持显示范围
