## 🐛 修：「导出当前图」不认标签页——在「数据比较」页点它，导出的还是光谱全图（用户反馈）

**症状**：在「数据比较」页看着那张「指标 - 变量」点线图，点「导出当前图」
（或 Ctrl+E / Ctrl+S），存下来的却是**预览页的光谱图**；数据比较图根本没有导出入口。

**原因**：`export_plot()` 里写死了 `self._savefig_pub(self.canvas.fig, ...)`——
`self.canvas` 永远是「预览」页那块画布。v4.37 新增的「数据比较」页用的是
`compare_canvas`，导出这条路没跟着扩。默认文件名也一样，取的是
`_current_plot_title()`（光谱标题）。

（顺带说明：菜单里的「**导出全部图片**」是好的——它本来就单独把
`compare_canvas.fig` 一起写了；出问题的只有「导出当前图」这一条。）

**修法**（v4.42）：

- 新增 `_current_export_canvas()`：按 `tab_widget.currentWidget()` **认页**
  （不是按索引——「寿命分布 / 拟合诊断 / 数据比较」会随模式显隐，索引会漂），
  映射表 `_TAB_CANVAS_PAIRS` 覆盖四个页：预览 / 数据比较 / 拟合诊断 / 寿命分布；
- 新增 `_current_export_title()`：默认文件名跟着当前页走——
  数据比较页给出 `数据比较_RB浓度_peak_intensity`（与「导出全部图片」的命名一致），
  诊断页 `拟合诊断`，分布页 `寿命分布`，预览页仍是原来的光谱标题；
- 导出菜单项与帮助里的文案改成「按当前标签页」，避免再被误解。

**验证**：吸收模式加载 `20261010`（7 条吸收光谱）→ 按 RB浓度画数据比较
（3 个点：10/20/50）→ 停在「数据比较」页导出，得到的 PNG 就是那张点线图
（`最大吸收（全谱）- RB浓度`，图例「全部样品（3 个）」）；切回「预览」页导出，
得到的仍是光谱图。两条路径都实测存盘 + 看图确认。
