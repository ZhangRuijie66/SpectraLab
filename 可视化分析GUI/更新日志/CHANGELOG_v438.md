## 🆕 一、寿命拟合的范围输入改成 τ（ns），不用再自己换算速率 k

**做什么**：荧光寿命模式的「寿命拟合」组里，原来两个输入框是**速率**
`k_min (1/ns)` / `k_max (1/ns)`（k = 1/τ），现在直接改成**寿命**
`τ_min (ns)` / `τ_max (ns)`——填的数值就是你要拟合的寿命范围，直观得多。

- **对应关系**（程序内部照旧在速率域拟合，只是输入层换算）：
  `k_max = 1/τ_min`（τ_min = 最短分量 = 最快衰减）、
  `k_min = 1/τ_max`（τ_max = 最长分量 = 最慢衰减）。
- **默认值不变**：`τ_min = 0.01 ns`、`τ_max = 100 ns`，
  即原来的 `k_max = 100` / `k_min = 0.01`（1/ns）。
- **两个框都不设实际的上限**（用户反馈后定稿）：唯一要求是 τ > 0，
  输入框最大值 `1e9 ns`（= 1 s）只是 `QDoubleSpinBox` 需要的有限值。
  例如 `τ_min` 可以填 **50 ns**（只看 >50 ns 的长寿命成分，旧版被 10 ns 夹住），
  `τ_max` 可以填 `1e6 ns`（1 ms）——旧版的 1e5 上限也一并去掉。
  下限仍是 0.001 ns = 1 ps（再小的寿命在 ns 单位的拟合网格上没有意义）。
- **两个框互相约束**（`_sync_lifetime_tau_range`）：谁被填到越界，另一个框
  自动让路——改 `τ_max` 到 τ_min 以下 → `τ_min` 退到 `τ_max/10`；
  改 `τ_min` 到 τ_max 以上 → `τ_max` 抬到 `τ_min×10`；状态栏回显调整后的范围。
  这样避免了"填了没生效"（原来越界会静默回退默认 0.01–100 ns）。
  兜底路径（设置里存了坏值等）仍回退默认范围，但现在会**同时写日志 + 状态栏提示**。
- 两个框都有 **tooltip** 写明「对应哪个速率」，鼠标悬停即可看。

**旧配置自动迁移**：升级后第一次启动，程序会把上次会话与「存为默认值」里存的
旧 `k_min/k_max` **一次性换算**成 τ（`τ_min = 1/k_max`、`τ_max = 1/k_min`）再套用，
所以自定义过范围的老用户不会因为升级而拿到错误的范围。
（迁移只做一次，标记 `migrated/tau_range_v438`；之后新填的 τ 不会被覆盖。）

## 🔧 三、改动文件

- `gui_ui.py`：两个输入框换成 `τ_min (ns)` / `τ_max (ns)`（含 tooltip、量程、步长），
  组内帮助文字与「存为默认值」tooltip 同步改口径；新增 `_sync_lifetime_tau_range`
  让两个框互相约束（保证 τ_min < τ_max）；
- `gui_plot.py`：`_collect_plot_params` 读 τ 后换算 `k_min = 1/τ_max`、
  `k_max = 1/τ_min`，其余拟合/缓存/导出路径**不改**（缓存键仍用换算后的 k，
  所以「叠加分布 / 汇总图 / PDF 报告」照样能复用单文件的拟合结果）；
- `gui_data.py`：会话与默认值设置键 `lifetime_kmin/kmax` → `lifetime_taumin/taumax`，
  新增 `_migrate_lifetime_range_keys`（在 `_restore_session` 开头执行一次）；
- `docs/用户手册.md`：8.2 节改为「寿命范围 τ_min / τ_max」、参数速查表、Q2/Q3 排查项、
  会话恢复清单同步；`便携版/使用说明.txt` 同步。
