## 🆕 一、「数据比较」模块：按说明.xlsx 的变量画强度-变量点线图

**做什么**：吸收 / 发射模式下，文件夹里有 `说明.xlsx` 时，参数栏多一个
「**数据比较（说明.xlsx）**」组——把每条光谱压成**一个纵轴读数**，再按某个变量的值
散点连线，回答"强度/面积随浓度怎么变"。

- **横轴变量**：`说明.xlsx` 的某个**数值列**（如 `RB浓度`）；没有说明.xlsx / 没有数值列 /
  该 .xlsx 与文件名对不上编号时按钮置灰，悬停给出原因。
- **分组变量（可选）**：再选一个数值列，每组一条点线（例如横轴 `RB浓度`、
  按 `L8i浓度` 分组 → 每个 L8i 浓度一条曲线）。
- **纵轴指标**（三种口径）：
  - `峰强度`：区间内最大强度（吸收模式显示为「最大吸收」）；
  - `峰面积`：区间积分，**默认复用下方「光谱积分」的起止波长**——两者现在共用
    同一份实现（`plot_compare.integrate_band`），数字必然一致；
  - `指定波长处的值`：该波长处线性插值，范围外**不外推**（直接跳过该样品）。
- **出图位置**：新增「**数据比较**」标签页（吸收/发射模式可见，寿命/3D 隐藏）；
  按钮点完自动切到该页，`⤓ CSV` 导出取点结果（`样品, 编号, 变量, 分组, 指标值`）；
  「导出全部图片」会连这张图一起导出。
- 只统计**左侧勾选**的样品；曲线口径与预览图一致（启用减法时用扣本底后的曲线）。

**新模块** `plot_compare.py`（独立模块 + 命令行 + `plot_compare使用说明.md`）：

```bash
python plot_compare.py "D:\data\20260825" --list-vars
python plot_compare.py "D:\data\20260825" --x RB浓度 --group L8i浓度 \
    --metric peak_intensity --band 560 620
```

## 🐛 二、说明.xlsx 里为 null / 空的变量不再显示（检查结果：两类都修了）

**症状**：说明.xlsx 里某样品某个变量没填时，程序仍会把它显示出来（如
`RB浓度=null`），甚至参与数据比较。

**检查结论**：分两种"空"，原来只处理了第一种。

1. **Excel 真正的空单元格**（读进来是 `NaN`）：`read_xlsx_info._clean_value` 早就
   会把 `NaN` 转成空串并在展示时跳过——这部分原本是对的。
2. **文本形式的空值**：单元格里手打的 `null` / `NULL` / `None` / `N/A` / `#N/A` /
   `NA` / `-` / `--` / `—` 等，以前被当成**有效值**原样显示（`RB浓度=null`）。
   → v4.37 起统一按空值丢弃（`_NULL_TOKENS`）；「无」「未测」这类可能是有意义的
   备注内容，**不**当空值处理（避免误删信息）。

**连带修的显示面**：

- 图例标签（合并图/单图）：空值变量不再出现，如 `RB浓度=50, 样品`；
- `信息` 页新增一行 `说明.xlsx: <变量>`，**只列有值的变量**（空的不显示）；
- `数据比较` 点线图：缺该变量值的样品**不进入图**（不会出现 `nan` 点、也不补 0），
  并在状态栏与画布悬停提示里说明**是哪几条、为什么**（含「匹配不到编号」）；
- 新增 `XlsxInfo.value_for(编号, 列)` 与 `XlsxInfo.numeric_columns()`：
  "没有值"返回 `None`，与"值为 0"严格区分（0 是有效值）。

真实数据验证：`20260903-2\说明.xlsx` 的 `编号 570`（Ce6浓度/L8i浓度为空、备注
「RB参比」）现在只在图例里显示 `RB参比`；四条 `RB-570-*` 光谱在数据比较里被明确
跳过并给出原因。

## 🆕 三、荧光寿命「叠加分布」可以只画勾选的样品

寿命模式以前**没有勾选框**（那时没有寿命合并图）。现在数据栏恢复勾选框，并且：

- 「**叠加分布**」只对**勾选**的样品并行拟合与叠加；
- 「跨样品汇总图」「PDF 报告」同样**只处理勾选**的样品；
- 状态栏文案给出「勾选 N/M 个样品」；一个都没勾时提示先勾选（不再默默按全部算）；
- 点某个文件名仍是单独拟合查看它（与勾选无关）；
- 已有拟合结果照旧复用（v4.23 的缓存机制不变），所以换勾选再出图几乎不用等。

## 🆕 四、光谱积分结果表只显示勾选的样品

以前积分扫的是"所有已加载样品"，会出现**表里有、图上没有**的样品（v4.36 那个
"启用减法后无法积分"的坑正是被这类样品引爆的）。现在统一为：

- 积分 = **勾选 ∩ 已加载**，与图上曲线一一对应；
- 一个都没勾时计数标签写「未勾选任何样品（积分只统计左侧勾选项）」，不给一张空表；
- 扣不了本底的样品仍按 v4.36 的做法只跳过自己并在悬停提示里说明。
