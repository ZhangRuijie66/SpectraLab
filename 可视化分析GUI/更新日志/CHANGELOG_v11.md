# 🆕 1.1 版本更新说明

**版本**：v1.1
**日期**：2026-08-26

---

## ✨ 新增功能

### 1. 📝 自定义绘图标题
- 新增 **"绘图标题"** 输入框，位于"图表类型"下拉框下方
- 可以自定义合并图和单独图的标题文字
- 留空时使用默认标题（合并图默认"吸收光谱对比"，单独图默认"吸收光谱 - {文件名}"）
- 修改标题后自动实时刷新绘图

### 2. ☑️ 自由选择数据绘制合并图
- 文件列表中的每个文件现在都有**复选框**
- 可以自由勾选/取消勾选要绘制合并图的数据
- 只有被勾选的文件才会显示在合并图中
- 修改勾选状态后自动实时刷新绘图
- 批量导出功能也遵循勾选状态（只导出勾选的文件）

## 🔧 优化改进

### 3. 🔍 提示性文字全面增大（含自适应DPT缩放）
- **全局基础字体**：14pt（随屏幕DPI自动缩放，最高1.5倍）
- **所有参数标签**（"图表类型"、"线宽"、"分辨率 (DPI)"、"颜色方案"、"宽度/高度"、"峰高度阈值"、"峰最小间距" 等）统一 **19px**
- GroupBox标题（"数据源"、"绘图参数"、"操作"、"峰检测参数"）**14pt 加粗**
- 文件夹信息（"未选择文件夹"）**20px 加粗**
- 文件列表标签 **18px 加粗**
- 标题输入框、信息标签 **18px**
- 下拉框、输入框、数值框 **17px**
- 复选框（"标记吸收峰"）**17px**
- 状态栏 **14pt**
- 主要操作按钮 × **16pt**，"选择文件夹"按钮 **14pt**
- **新增高分屏自适应**：程序启动时按屏幕 DPI 自动调整基础字体（96DPI为基准，更高DPI自动放大）

> **适配高分辨率说明**：QQ字体用 px(pixel) 设置，Qt 会根据系统 DPI 缩放自动处理；同时程序在 `main()` 中启用了 `AA_EnableHighDpiScaling` 并依据屏幕逻辑DPI自动放大基础字体，因此在 2K/4K 高分屏上字体也会同步放大，不再显得过小。

### 4. 🎨 绘图风格与 plot_emission 保持一致
- **颜色方案**：改用与 plot_emission 一致的 **Set1** 配色（`plt.cm.Set1`）
- **峰标记方式**：改用 `annotate` 文字标注（在峰值上方显示峰位 nm 值），替代原先的散点标记
- **标题样式**：统一为 `fontsize=13`
- **坐标轴标签**：统一为 "波长 (nm)" 和 "吸收值 (AU)"
- **图例**：`fontsize=9`，**网格**：`alpha=0.3`
- 中文字体设置与 plot_emission 使用相同的候选字体列表

## 🚀 使用方法

### 自定义标题
```
1. 在"绘图标题"输入框中输入想要显示的标题
2. 绘图会自动刷新
3. 清空输入框恢复默认标题
```

### 选择数据绘制合并图
```
1. 加载数据后，文件列表中每个文件前有复选框
2. 勾选想显示在合并图中的文件
3. 取消勾选不想显示的文件
4. 合并图会自动更新，只显示勾选的数据
```

## 📐 图形比例（长宽比）选项（v1.1 增补）

在参数面板新增 **"图形比例"** 下拉框，用于控制绘图/图形的长宽比：

```
自动 (随窗口)  ← 默认，画布随窗口缩放
16:9          ← 宽屏比例
16:10
4:3
3:2
1:1           ← 正方形
2:1
```

- 选择具体比例后，图形（含导出的图片）保持该长宽比
- 选择"自动"则画布完全随窗口缩放
- 画布已实现随窗口自适应缩放，切换比例自动实时刷新

## 🌈 发射光谱绘制功能（v1.1 增补）

### 光谱类型切换
- 数据源面板顶部新增**"光谱类型"下拉框**
- **吸收光谱 (UV-Vis)** / **发射光谱 (Emission)** 一键切换
- 切换后自动用对应逻辑加载和绘图，共用目录树/参数/画布

### 发射光谱数据加载
- 复用 `plot_emission` 模块的 `load_spectra`，自动解析 Spectracle / RF-6000 等发射光谱格式
- 自动提取 **激发波长 (EX)**、发射波长、强度
- 一个文件可能包含多条光谱，全部加载并列出

### 发射光谱专用选项
- ✅ **归一化强度**：将各光谱归一化到 [0,1] 便于对比
- ✅ **标注激发波长 (EX)**：曲线上画出激发波长虚线
- ✅ **标记峰**：自动标注发射峰位

### 发射光谱绘图
- **合并图**：多条发射光谱叠加对比（Set1 配色）
- **单独图**：单条发射光谱 + 峰标注 + EX 虚线
- 自动跳过激发光谱（Spectrum Type=Excitation）
- Y 轴标签自动切换为"发射强度 (AU)"

### 技术点
- 修复了发射模块 emoji 打印导致的 GBK 编码报错（程序启动设置 UTF-8 输出）
- 新增 `clear_fig()` 安全清空画布，避免 constrained_layout 下重复绘图的 KeyError
- 峰检测使用 `scipy.signal.find_peaks`（发射强度阈值按峰值比例计算）
