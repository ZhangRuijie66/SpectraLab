## 🐛 一、修：微秒模式下 IRF 曲线整条看不见（v4.39 引入，用户反馈）

**症状**：把「时间单位」切到**微秒**后，拟合图例里还写着 `IRF（平移 2.2 μs）`，
但图上**找不到那条黄色 IRF 曲线**——整条消失了。

**原因**：v4.39 引入单位显示时，把「时间量要换算」误用到了 IRF 上：

```python
irf_d = irf_shifted / ltu        # ← irf_shifted 是**强度**（counts），不是时间！
ax1.plot(time_d, irf_d, ...)
```

横轴换成 μs（除以 1000）是对的，但 IRF 的**强度**也被除了 1000 →
在 log 纵轴上从 `0–635.9` 掉到 `0–0.636`，而 y 轴下限是 `1` →
整条曲线落在坐标轴范围以下，完全不可见（ns 模式下 `ltu = 1`，所以只有 μs 模式暴露）。

**修法**：只换算**时间量**（横轴 / qshift / τ），强度量（IRF、衰减、拟合曲线、
残差、散点）一律不动。已加注释标明这条边界，避免以后再踩。

**验证**（真实数据 `Ce6 lifetime.csv`，μs 模式 τ 0.5–50 μs）：修复后
IRF 线 y 范围 `0–635.9`（与 ns 模式逐点相同）、`ylim = 1–993.6`（与 ns 模式相同）、
χ²R = 2.764，与修复前 ns 模式的 2.765 一致。

## ✅ 二、新增回归用例，专门盯住"强度不许被换算"

`GUI：μs 单位只换时间轴，IRF/衰减/拟合的**强度**不被换算（v4.40）`：

- 合成一份计数刻度的数据（SESM 拟合，秒级）→ 用 ns 与 μs 各渲染一次；
- 断言 **IRF / 拟合曲线 / 实验数据散点的 y 值逐点相同**（只准换横轴）；
- 断言横轴按 1000 倍换算（`x_max(μs) × 1000 == x_max(ns)`）；
- 断言 **IRF 峰值仍在 y 轴范围内**、且两种单位的 y 轴范围相同
  —— 这正是"IRF 无法显示"的直接判据。

该用例已**先用注入 bug 的方式确认能抓到**（把 `irf_shifted / ltu` 写回去 → 用例报
「μs 模式下 IRF 强度被误改」），再恢复修复。

另外 `tests/test_lifetime_unit_smoke.py` 也补了同样口径的 IRF 断言
（真实数据端到端）。
