## 一、帮助窗口重做（新增 `gui_help.py`）

### 旧实现的问题

`F1` 与入口界面「？」都是一次性 `QMessageBox.about()` + 一大段富文本。
实测 **722 × 600 逻辑像素**，占可用高度（852）的 **70%**，
不可滚动、不可复制、宽度不可调、没有搜索——再加内容就溢出屏幕。

### 新实现

新增独立模块 `gui_help.py`（`HelpDialog` + `show_help_dialog()`）：

- **非模态窗口**（720×560 起，可缩放，尺寸记进 QSettings）：可以一边看图一边查帮助；
- 左侧**小节目录**（当前模式 / 快捷键 / 其它），点击跳转；
- 右侧 **QTextBrowser 可滚动正文**，可框选复制；
- 顶部**搜索框**（`QTextBrowser.find`，命中会提示、未命中会提示）；
- 底部 **📋 复制全部**（一键把全部正文纯文本放进剪贴板）、
  **📂 打开日志文件夹**、**关闭**；底部一行显示日志路径；
- 颜色**全部来自 `theme_palette()`**，模块内不硬编码任何颜色值
  → 深色/浅色都正确，不再出现白块；
- 主题切换后再按 F1，会 `apply_palette()` 重刷样式表
  （否则会复用切换前的浅色样式表，深色界面里弹出一块白底正文——开发中实测踩到并修掉）；
- 同一小节内容不变时复用同一个窗口，只提到前台，不会堆一屏帮助窗口；
- 正文拆成结构化小节（`[(标题, HTML), ...]`），以后加模块只加一节，不用再拼字符串。

`gui_ui.show_help()` 与 `gui_launcher.show_help()`（入口界面标题栏「？」）
都改走这个窗口。

## 二、深色模式补齐

### 1. 画布分层：不再和窗口糊成一片

深色主题原来 `MPL_FIG = #0f172a` 与窗口底色 `BG` **完全相同**、
`MPL_AX = #1e293b` 又与卡片 `CARD` 完全相同，于是画布边界消失，
图表像"挖了个洞"浮在窗口里。现在：

- `MPL_FIG` 调深到 `#0b1220`（比窗口更深一档，形成"深色图纸"）；
- `QTabWidget::pane` 加 **4px 内边距**，让画布四周留出一圈卡纸边。

> 注：深色下"更深"能拉开的对比度有物理上限（黑是硬下限，画布 vs 窗口最多约
> 1.17:1），所以真正的边界感来自这圈内边距 + pane 描边，颜色只是辅助。

### 2. 选中态对比度

深色 `SELECT_BG` 从 `#1e3a5f` 提到 `#2b5285`、`SELECT_FG` 从 `#93c5fd` 提到
`#bfdbfe`：原值对卡片底色 `#1e293b` 只有约 **1.3:1**，选中项几乎看不见，
现在约 **1.9:1**。

### 3. 遗留（本批**未**做，见 §五）

启动画面 `splash.png` 仍是浅色卡片。

## 三、目录树栏与文案收口（治"挤 + 截断 + 参差"）

| 问题（v4.23 实测） | 本版改法 |
|---|---|
| 顶部三个按钮宽度 160 / 160 / 自适应，左边缘参差，🏠🌙 纯色块 + ❓ 白底下拉按钮三套视觉语言 | 统一成 **3 个等宽 ghost 图标按钮**（36×30，一行排开），说明全部进 tooltip：🏠 返回模块选择 / 🌙☀️ 切换主题 / ❓ 帮助菜单 |
| 「工作区: D:\北大\…\光谱」自动换行占 **3 行** | `_short_path()` 缩成 `…\谱图\光谱` **单行**，完整路径进 tooltip |
| 「文件夹: …\test2\n已加载 7 个文件」两行 | 单行短路径；文件数保留在「数据」栏的计数标签里，tooltip 里也带 |
| 光谱类型下拉显示成「吸收光谱（UV-」 | 选项改中文短名（吸收光谱/发射光谱/荧光寿命/3D 扫描），英文全称进**每项 tooltip** |
| 「选择工作区」「选择文件夹」两个彩色实心大按钮并排 → 200px 栏里每个只剩 ~77px，中文标签被切一半 | 「选择数据文件夹」独占一行做本栏主操作；「选择工作区」降级为路径行上的 📂 小图标按钮（低频操作） |
| 「已加载的文件（勾选以绘制合并图）:」标题被截断 | 标题收成「已加载文件」，各模式的完整提示进 tooltip |
| 「选择数据文件夹（双击子文件夹加载）:」被截断 | 收成「目录（双击加载）」+ tooltip |
| 文件名一律被省略号截断（数据栏仅 210px） | 列表每一项自动挂**完整文件名 tooltip**（`_sync_file_item_tooltips`，`item.text()` 本就是完整的） |
| 控件说明散落各处 | 目录树/数据/参数各栏关键控件补齐 tooltip（含 Ctrl+O、Ctrl+T、F1 等快捷键提示） |

派生效果：目录树栏少了 2 个饱和色实心按钮、少了 3 行折行文字，
首屏信息密度下降、可读性上升。**「操作」区那 6 个彩虹按钮留到第 2 批**
（要配合按钮体系与导出菜单一起改，单独改会半途而废）。

## 七、备注

- 交互行为差异（请注意）：帮助窗口现在是**非模态**的，不会再挡住主窗口；
  同一小节重复按 F1 只把窗口提到前台；关掉后再按 F1 重新打开（尺寸沿用上次调整的）。
- `QMessageBox` 仍用于警告/确认等场景，不受本版影响。
