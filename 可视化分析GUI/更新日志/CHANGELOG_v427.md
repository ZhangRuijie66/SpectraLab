## 一、matplotlib 工具条中文化

画布上方那条工具条原本是 **英文 tooltip**（Home / Back / Forward / Pan / Zoom /
Customize / Save），其中 `Customize` 那个按钮**连图标都没有**（Qt 主题里没有
`help` 图标，显示成一个空按钮），用户基本不知道它能干什么。现在：

| 位置 | 中文名 | tooltip（含快捷键） |
|---|---|---|
| 1 | 复位视图 | 恢复到初始缩放/平移状态（h） |
| 2 | 上一视图 / 下一视图 | 视图历史前进后退（← c / → v） |
| 4 | 平移 | 按住左键拖动画面（p） |
| 5 | 框选缩放 | 左键拖框放大、右键拖框缩小（o） |
| 6 | 调整边距 | 打开边距对话框手工微调（f） |
| 7 | 曲线参数 | 编辑坐标轴/曲线/图像参数（原来的 "Customize" 空按钮） |
| 9 | 保存图片 | 另存当前画布（程序自己的导出在「💾 导出 ▾」） |

右下角的坐标读数标签也补了 tooltip（"当前鼠标位置的数据坐标"）。
三个画布（预览 / 寿命分布 / 拟合诊断）的工具条都做了同样处理。

> 分组分隔线保持 mpl 自带的（视图 | 缩放参数 | 保存）。
> 开发中我先按方案「自己再插两条分隔」实现，结果**每处都变成双线**——
> mpl 的 `toolitems` 里本来就带 `None` 分隔项，所以最终只改文字、不动分隔。

## 二、画布空状态引导（治「一片空白不知道点哪」）

原来没加载数据时，画布上只有一行居中小灰字。现在画布页变成**两页堆叠**：
有数据 → 画布；没数据 → 空状态引导页：

- 居中大图标（`icons\folder_open_<theme>.png`，缺图标时自动退回 emoji）；
- 标题「还没有加载数据」，或者数据文件夹解析出 0 个文件时显示
  「该文件夹没有解析出可用数据」（并带上短路径 + 提示按 F1 看支持的格式）；
- 一行引导（"把数据文件夹拖到窗口上，或点下面的按钮选择"）；
- 一个主按钮 **`选择数据文件夹`**（与左栏那个按钮同一动作，Ctrl+O 也可）。

细节：空状态下那条 matplotlib 工具条会一起收起（没有图可操作，留着只是噪音），
一加载数据就自动回来。

## 三、信息页卡片化 + 拟合质量徽标

信息页原来是一整页纯文本 `QLabel`：字号一致、没有层级，一大片看不出重点。现在：

- **卡片 1「文件信息」**：原有正文一行不改，装进卡片、放进滚动区，
  并允许**框选复制**（原来只能看，想抄一个数得手打）；
- **卡片 2「拟合摘要」**（寿命模式拟合完成后才出现，没拟合过则整卡隐藏）：
  - **质量徽标**：`拟合质量 ok / poor / failed` 三档药丸标签，
    颜色取自色板（绿 / 橙 / 红三档，深浅主题各有配套底色）。
    对应 `plot_lifetime` 的 `quality`：ok = χ²R 接近 1 且收敛、
    poor = χ²R 偏大/未收敛/边界堆积、failed = χ²R 非有限；
  - 一行摘要：`χ²R · 拟合点数 M · Durbin–Watson`，质量不是 ok 时追加具体原因；
  - **寿命分量表**：分量 / τ (ns) / 占比 (%)，固定分量单独标注成
    `固定 τ = 0.5`，点表头可排序（τ 列按**数值**排）。
- 状态栏的进度条也从参数栏顶部**搬到了状态栏**（原来是固定占位的第二条进度条，
  既占纵向空间又和状态栏信息重复），属性名不变，加载/拟合代码一行没改。

## 四、状态栏：进度 + 两个徽标

状态栏现在是三段式：

```
[状态文字 ………………………………………]   [进度条(仅忙碌时出现)]  [吸收光谱]  [7 个样品]
```

- 进度条空闲时完全隐藏（不占位），加载/拟合时出现并走字；
- **模式徽标**随「光谱类型」下拉框切换（吸收光谱 / 发射光谱 / 荧光寿命 / 3D 扫描）；
- **样品数徽标**随数据栏列表实时更新（含搜索过滤后的计数逻辑）。

## 五、顺带修掉的两个问题

1. **mac 同步清单漏了三个运行时模块**（潜伏已久）：
   `gui_log.py`（被 `gui_data` / `gui_plot` **模块级**导入）、
   `gui_help.py`（v4.24 起被 `gui_ui` 使用）、`gui_icons.py`（本版新增）。
   `同步到mac文件夹.ps1` 的 SYNC-MANIFEST 是"唯一真源"，但清单里根本没有这三个 ——
   于是同步检查**全绿**，而 mac 副本一打包就会 ImportError。
   现在清单补齐（24 → **28 条**，展开 136 个文件，SHA256 全一致），
   并给 `build_mac.command` 补了 `--hidden-import gui_help / gui_icons`。
2. **后台绘图线程不再吞掉堆栈**：`PlotWorker` 原来只把 `str(e)` 抛给界面，
   日志里只剩一句「wrapped C/C++ object … has been deleted」这类没法定位的信息；
   现在同时把**完整堆栈**写进程序日志（错误框文案不变）。

> 另注：`同步到mac文件夹.ps1` 必须存成 **UTF-8 带 BOM**（脚本头部自己写了这条），
> 用编辑器改这个文件时很容易把 BOM 丢掉——丢了之后 PowerShell 5.1 会把中文读成乱码、
> 整个脚本语法报错。本版踩到并已恢复，后续改这个文件请注意。
