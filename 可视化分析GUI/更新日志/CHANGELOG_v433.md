## ✨ 改进：叠加寿命分布不再逐条归一，图例给出振幅与实际强度

### 1. 纵轴改为「同刻度」——不再每条曲线各自归一

旧实现把每条分布曲线都除以**自身**最大值：

```python
mx = float(np.max(dist))
ax.plot(tau, dist / mx, ...)     # 每条曲线峰高都被拉到 1
```

结果所有曲线峰高一律 = 1，**曲线之间的幅度差被完全抹掉**，只剩形状。

现在改为所有曲线共用**同一个**比例因子（全部曲线的全局最大值）：

```python
scale = max(每条曲线的 dist.max())
ax.plot(tau, dist / scale, ...)   # 只有最大的那条到 1，其余按真实比例
```

于是曲线间的高度差得以保留，同时同一尺度下依然比得出形状。
纵轴标签改为「分布强度（同刻度，未逐条归一）」。

### 2. 图例同时给出「振幅 A」与「实际强度 I」

新的图例每条形如：

```
topic5 - 副本·pure-Trp
    A=0.8566 a.u.（81.8%）  I=8.483e+09 counts
```

两个量口径不同，缺一不可：

| 记号 | 含义 | 口径 / 用途 |
|---|---|---|
| **A** | `k_distribution` 的峰值，即该曲线未缩放时的最高点 | 反映分布的**集中程度**（λ 越强越弥散、A 越小）。拟合内部已按 decay_max 归一（`x_fit = 峰高/decay_max`），所以 **A 与样品整体亮度无关** |
| **I** | 该样品衰减曲线在**拟合窗口内**的总计数 | 跨样品真正可比的"亮不亮"；整体衰减倍数会在 A 里被约掉，只有总计数留得住。同时决定统计噪声水平 |

A 按百分比给出（A / 全局最大 A）×100：分布是形状量，绝对刻度没有物理意义，
百分比才看得出"集中/弥散"；I 给绝对值（counts）便于跨样品直接比较。

### 3. 修掉一个口径不一致（图例 I 与拟合刻度）

图例最初直接读 `r['decay']` 求和，但若该文件是归一化数据，`preprocess` 已把它
还原到 1e4 刻度再拟合——于是图例显示的 I 比拟合实际使用的计数小 4~5 个量级，
与 A、与图上的曲线自相矛盾（实测 84.83 vs 8.483e5）。

现在图例乘上 `info['rescale_factor']`，与拟合实际使用的刻度统一。

### 4. 含归一化输入时明确警告

各文件若被**各自**还原到 1e4 刻度，绝对刻度并不统一，此时 I **不可跨样品直接
比较**。纵轴会自动追加一行提示：

```
⚠ 含归一化输入，I 不可跨样品比
```

（该情形下若确实要比亮度，请让所有输入处于同一计数刻度。）

## ✅ 回归测试

新增 `GUI：寿命分布叠加不逐条归一，保留相对幅度（v4.33）`：

- 用 3 份**形状不同**的合成衰减（快/慢分量比例与寿命都不同）验证；
- 断言「所有曲线峰高都等于 1」**不成立**（旧 bug 回归保护）、全局最大那条为 1；
- 断言绘图峰高 == 原始幅度比（无额外变形）；
- 断言每条图例同时含 `A=`/`a.u.` 与 `I=`/`counts`；
- 断言图例 I == 「窗口内总计数 × 还原因子」，锁住第 3 条修的口径。

全套回归：**57 项通过 / 0 失败**（v4.32 为 56 项）。

> 测试过程中确认了一个容易误判的点：`k_distribution` 是**相对幅度**，拟合内部
> 已按 decay_max 归一，所以把同一段衰减整体乘 0.5 / 0.25 后拟合，分布**完全不变**
> （实测 k_dist.max = 0.672 / 0.666 / 0.679）。即"整体衰减倍数"不体现在分布上，
> 样本间差异来自分布形状——这也是图例要同时给 I 的原因。
