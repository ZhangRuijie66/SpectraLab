## ✨ 改进：单独拟合的寿命分布图例给出每个组分的振幅与强度占比

单独点「开始拟合」后，「**寿命分布**」页的图例，对**每个分离出的组分**同时给出
**振幅占比**与**强度占比**：

```
旧：τ₁ = 0.665 ns, α = 0.0154
新：τ₁ = 0.665 ns, 振幅 6.9%, 强度 1.5%
```

两个口径物理意义不同，数值**可以差很多**，缺一不可：

| 记号 | 含义 | 口径 |
|---|---|---|
| **振幅占比** | 该高斯分量在 k 空间的**峰高**（`fit_pars[:,0]`），按最大者归一为百分比 | 分布"**尖不尖**"。窄而快的伪分量峰可以很高 |
| **强度占比** | 该分量的**发光强度贡献**（∝ 幅值/k 的积分，等价于分布下面积），各分量之和 = 100% | "这个组分是不是真正的**主发光体**" |

**为什么必须两个都给**：强度 ∝ 幅值/k 的积分 → **宽而慢**的分量强度大而峰不高；
**窄而快**的分量峰高却几乎不发光（多为上升沿形状失配的吸收器）。只看振幅会误判
谁在发光；只看强度则看不出分布是否被一个尖峰撑起来。

实测（topic5 / 纯 Trp，MEM + auto-λ）：

| τ (ns) | 强度占比 | 振幅占比 |
|---|---|---|
| 0.665 | 1.54% | 6.89% |
| 2.959 | 98.46% | 100.00% |

即那个 0.67 ns 的快分量"峰不算小"（振幅 6.9%），但几乎不发光（强度仅 1.5%）
——正是需要区分的情形。

### 实现

- `postprocess()` 新增振幅占比计算，写入 `info['peak_amplitude_share']`，并作为
  **第 5 项**追加进 `peak_result` 每项：
  `[tau, 强度占比, FWHM(k), 强度占比, 振幅占比]`。
  追加是兼容的：既有消费者都用 `p[0..3]` 索引或 4 元解包（末尾是 `_`）；
  已同步修正 `postprocess` 内部那处 4 元解包的日志循环。
  丢弃低强度噪声分量（< 0.5%）后振幅占比会重新归一，保证最大者仍为 100%。
- GUI `_render_lifetime_result` 与独立模块 `plot_lifetime` 的对应图例同步更新，
  且对**旧结果 json**（`peak_result` 只有 4 项）回退为按分量峰高自算振幅。
- `info` 页与日志同步：日志行改为「强度占比 = …, 振幅占比 = …」。

## ✨ 改进：叠加寿命分布不再逐条归一

叠加图旧实现把每条分布曲线都除以**自身**最大值：

```python
ax.plot(tau, dist / dist.max(), ...)   # 每条曲线峰高都被拉到 1
```

结果所有曲线峰高一律 = 1，**曲线之间的幅度差被完全抹掉**，只剩形状。

现在所有曲线共用**同一个**比例因子（全部曲线的全局最大值）：

```python
scale = max(每条曲线的 dist.max())
ax.plot(tau, dist / scale, ...)        # 只有最大的那条到 1，其余按真实比例
```

曲线间高度差得以保留，同一尺度下依然比得出形状。纵轴标签改为
「分布强度（同刻度，未逐条归一）」。

叠加图的图例还附上该类样品的**分布振幅 A**（`k_distribution` 峰值，给 a.u. 与
占全局最大的百分比）与**窗口内总计数 I**（counts）。其中 I 乘过
`info['rescale_factor']`，与拟合实际使用的刻度统一；若某些输入是归一化数据
（各自被还原到 1e4 刻度），各曲线绝对刻度不统一，纵轴会追加一行
「⚠ 含归一化输入，I 不可跨样品比」。
