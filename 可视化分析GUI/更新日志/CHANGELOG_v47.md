# 🔬 4.7 版本更新说明

**版本**：v4.7
**日期**：2026-08-31

---

## ✨ 新增：光谱减法（吸收/发射模式）

参数面板新增「光谱减法」组（寿命模式下自动隐藏）：

- **扣除本底**：勾选「启用光谱减法」后，所有绘制的光谱都减去所选本底 B
  （如参比/空白 RB），本底文件本身不再绘制；合并图与单独图、预览与导出全部生效。
- **两光谱相减 (A − B)**：减法模式切到「两光谱相减」后选择被减光谱 A 与减数 B，
  只绘制一条 A − B 差谱，标题为「XX光谱相减 - A − B」，可标记差谱上的峰。
- 波长网格不一致的两条光谱会自动**插值对齐并裁剪到重叠波长区间**后相减。
- 「导出全部图片」在差谱模式下直接按标题导出当前差谱图。
- 文件加载后 A/B 下拉框自动填入已加载文件（默认 A = 第二个、B = 第一个，避免 A=B）。

## ✨ 改进：图例标签规范化（类型 + 样品信息）

- 图例统一附**光谱类型**：`(emission)` / `(absorption)`，发射模式同时附激发波长，
  如 `Ce6浓度=100, L8i浓度=1000 (emission, EX=676 nm)`。
- 有 说明.xlsx 且编号匹配到时，图例**只显示说明信息**，不再显示原文件名
  （如 "ce6-1"）；编号匹配不到的文件（如参比 RB）仍显示原名。
- 单图模式的**标题**改用样品名（不含说明信息），避免标题变成一长串浓度。

## ✨ 改进：导出文件名 = 图表标题

- 「导出图片」的默认文件名改为当前图表标题（自定义标题优先），
  发射光谱图不再默认叫 `absorption_combined.png` 这类名字。
- 「导出全部图片」的单独图/合并图文件名同样取各自标题，
  如 `发射光谱 - ce6-2.png`、`发射光谱对比.png`（替换 Windows 非法字符）。
- 「导出全部图片」补齐**发射模式**支持：图例/EX 竖线/归一化/峰标注与预览一致
  （此前发射模式下导出的图错误地按吸收光谱样式命名与标注）。

## ✨ 改进：图形比例对「寿命分布」画布生效且即时应用

- 「图形比例」下拉框现在**同时应用到主画布与寿命分布画布**，
  且切换比例立即调整画布尺寸（纯显示调整，寿命模式下**不需要重新拟合**）。

## ✨ 改进：导出分辨率默认 600 dpi

- DPI 范围扩到 72–1200，**默认值 200 → 600 dpi**，出图分辨率更高。

## 🐛 修复：绘图参数面板边框背景呈系统灰

- 参数列（QScrollArea）的 viewport 与内容容器背景改为透明，
  露出窗口默认背景色（#f1f5f9），不再是 Windows 默认的灰色块。
