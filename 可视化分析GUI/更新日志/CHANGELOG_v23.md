## ✨ 新增功能：读取文件夹中的 `说明.xlsx` 并写入图例

选择数据文件夹后，程序会自动识别该文件夹里的 **`说明.xlsx`**，把每个样品的
浓度、备注等信息自动写入曲线图例。

### 1. 🆕 新增独立模块 `read_xlsx_info.py`
- 通用读取 **`说明.xlsx`**，**自动识别「编号」列**（支持 `编号` / `序号` / `No.` /
  首列等），其余非空列一律作为信息列。
- 自动适配不同实验的列名：`ZnPcS4浓度`、`CPC浓度`、`RB浓度`、`L8i浓度`、
  `Ce6浓度`、`是否加入PVP`、`备注` 等均能识别，无需改代码。
- 提供 `load_xlsx_info()`、`match_number()`、`format_info()`、
  `build_enriched_label()`、`enrich_label_from_name()` 等接口，可在任意脚本中复用。
- 已在 `__init__.py` 统一导出。

### 2. 🖇️ 打通 GUI（`absorption_gui.py`）
- 加载文件夹后自动调用 `_load_xlsx_info()` 读取说明.xlsx；找不到则不影响原功能。
- 底部状态栏提示「已读取说明.xlsx：N 个样品（浓度等信息自动写入图例）」。
- 绘图（合并图 / 单独图 / 发射光谱 / 批量导出）的**图例标签**会自动增强：
  - 文件名能匹配到编号时，追加样品信息，如：
    `ce6-7（Ce6浓度=100, L8i浓度=1000, 是否加入PVP=是）`
  - 文件名本身就是编号时（如 `1.csv`），直接以 `#1 RB浓度=10, ...` 显示。
  - 匹配不到编号时，回退到原有文件名标签，不影响显示。

### 3. 🎯 编号匹配策略（`match_number`）
按优先级容错匹配「文件名 -> 编号」：
1. 整串就是编号且在该批次集合中。
2. 文件名按非字母/数字/汉字切分，取第一个命中集合的整数
   （`Zn-10-3.csv` → 命中 10，忽略重复测量的尾号 3）。
3. 编号作为「独立整数」出现在文件名中（避免 `Zn-10` 误命中子串 `1`）。
4. 均无命中 → 返回 `None`，图例使用原文件名。

## 🐞 本次同时修复的两个问题（v2.3 增补）

### 1. 🎨 调整「颜色方案」现在真正生效
- 此前 `get_color_map()` 虽读取颜色方案，但绘图函数硬编码 `plt.cm.Set1`，
  导致「蓝-红 / 绿-紫 / 彩虹」切换后颜色不变。
- 现改为统一使用所选颜色方案（新增 `_palette(color_map, n)` 生成颜色）：
  - 默认 (Default) → `Set1`（与 plot_emission 一致）
  - 蓝-红 (Blue-Red) → `Blues_r`
  - 绿-紫 (Green-Purple) → `viridis`
  - 彩虹 (Rainbow) → `rainbow`
- 合并图 / 单独图 / 发射光谱 / 批量导出均生效。

### 2. 🔢 数据按自然顺序排序
- 此前文件列表按字典序显示，出现「样品 1、10、11、2、3…」的乱序。
- 现改为自然排序（`_natural_key`）：按文件名中的数值比较，
  正确显示为「样品 1、2、3、…、10、11」。
- 例：`1.csv, 2.csv, 3.csv, …, 10.csv, 11.csv`；
  发射光谱的 `ce6-1-2.csv` 也会排在 `ce6-2.csv` 之前（对应样品 1 在样品 2 前）。

## 🧩 代码结构模块化（v2.3 增补）

把原本约 2100 行的单文件 `absorption_gui.py` 按职责拆分为多个可维护模块（行为不变）：

```
可视化分析GUI/
├── absorption_gui.py   ← 主程序入口（仅负责组装三个 Mixin，约 100 行）
├── gui_config.py       ← 全局常量配置（工作区、App 名、版本号、图标名）
├── gui_components.py   ← 可复用界面组件（PlotWorker/ComboItemDelegate/
│                         SliderSpin/MplCanvas + resource_path）
├── gui_ui.py           ← 界面样式 Mixin（面板搭建、QSS、中文字体、实时预览联动）
├── gui_data.py         ← 数据 Mixin（加载光谱/工作区/文件夹/信息/说明.xlsx 图例增强）
└── gui_plot.py         ← 绘图 Mixin（实时预览/合并图/单独图/发射光谱/颜色方案/导出）
```

- 三个 Mixin 通过 `AbsorptionGUI(UiMixin, DataMixin, PlotMixin, QMainWindow)` 组装，
  对外 API 与 `main()` 不变，全部启动脚本/打包脚本无需改动。
- PyInstaller 打包脚本新增对应 `--hidden-import`。

## 📦 重新打包说明（v2.3 增补）
- 已用 PyInstaller 重新打包单文件可移植版：
  `便携版\光谱可视化分析工具.exe`（约 107 MB，含 v2.3 全部功能）。
- 修复打包脚本 `打包便携版.ps1` 的编码问题：给脚本加上 UTF-8 BOM，
  避免 Windows PowerShell 5.1 读取含中文的 `.ps1` 时产生乱码/语法错误。
- 注：若在自动化测试环境里直接启动单文件 exe 出现
  “Failed to create parent directory structure”，多因该环境的临时目录不可写
  （PyInstaller onefile 启动时需解压到临时目录），并非程序本身问题；
  在正常桌面环境下双击即可运行。若目标机器临时目录受限或含非 ASCII 路径，
  可改用 `--onedir` 打包（无需解压到临时目录，更稳健）。
