## 0. 先说结论（TL;DR）

现在的界面**功能密度很高、但视觉层级是平的**：每一栏里都有 5–7 个**实心彩色按钮**，
主次不分；三栏最小宽度压在 655 px，而你的屏幕逻辑分辨率只有 **1440×852**，
于是文件名被截成 `2026082…`、下拉框显示成 `吸收光谱（UV-`、工作区路径折成 3 行；
参数区内容总高 **1963 px**，可视只有 783 px，要滚 2.5 屏。

**最值得做的 5 件事**（收益/成本比最高）：

| # | 改动 | 收益 | 成本 | 风险 |
|---|------|------|------|------|
| 1 | **按钮体系**：每区只留 1 个主色实心按钮，其余改白底描边/幽灵按钮，「操作」区合并成「▶ 实时预览」+「导出 ▾」菜单 | 立刻去掉"彩虹感"，主操作一眼可见 | 0.5 天 | 低（只动 `gui_ui`，不碰逻辑） |
| 2 | **帮助窗口重做**：`QMessageBox` → 固定尺寸可滚动窗口（含目录/复制） | 实测帮助框 500×596 逻辑像素、已占可用高度 70%，再多内容就溢出且不能滚动/复制 | 0.5 天 | 低 |
| 3 | **字阶与密度**：控件字号 15–16 px → 13 px，标签 12 px，组标题 15 px；行高/内边距统一到 4 的倍数 | 参数区内容高度约 −25%，滚动减少；截断明显缓解 | 0.5–1 天 | 低 |
| 4 | **三栏可折叠 + 宽度可拖**：左两栏合并成"一个可折叠侧栏"，图片区默认给更大宽度 | 画布从 ~700 px 提升到 ~1000+ px；图表是主角 | 1–1.5 天 | 中（动布局结构） |
| 5 | **深色模式补齐**：启动画面、选中色对比度、画布与卡片分层 | 深色下不再有"白块"和"糊成一片" | 0.5 天 | 低 |

## 2. 设计原则（先对齐审美）

1. **图表是主角**：所有界面元素都为"看清图、快速改图"服务；画布应占 ≥55% 宽度。
2. **一屏一个主操作**：同一时刻只允许一个实心主色按钮（primary），其余是描边按钮（secondary）或幽灵按钮（ghost）。
3. **颜色是语义，不是装饰**：绿=加载/成功、紫=拟合、橙/青=导出、灰=导航。语义色只用于**图标色 + 3 px 左侧条 + 悬停描边**，不做整块填充。
4. **克制的科研感**：低饱和、细边框（1 px）、小圆角（6–8 px）、无渐变、无投影（浮层除外）。
5. **信息可查全**：任何被截断的文本都要有 tooltip / 可展开视图——这是科研工具的基本要求（文件名、路径、参数单位）。
6. **深浅双主题同源**：所有颜色只能来自 `gui_config.THEMES`，不允许硬编码（v4.18 的老问题要防止回潮）。

## 3. 三个整体方案（请选一个）

### 方案 A｜保守微调（0.5–1 天，风险最低）
**只做"减法"，不动布局骨架。**
- 统一按钮体系（§5.1）、字阶（§5.2）、截断与 tooltip（§5.3）
- 帮助窗口重做（§6）
- 深色补齐（§4）
- 侧栏宽度改为可拖 + 记忆（QSplitter 已存在，只需放开最小宽度并保存）

*优点*：改动集中在 `gui_ui.py` / QSS，回归成本极低，一天内可验收。
*缺点*：三栏并排的拥挤只在字变小后"缓解"，画布仍只有 ~750 px。

### 方案 B｜工具栏 + 可折叠侧栏（1.5–2.5 天，**推荐**）
在 A 的基础上重排布局：
- 顶部加一条 **40 px 工具栏**：`📁 打开 ▾`、`🔄 重载`、`▶ 预览 / 开始拟合`、`💾 导出 ▾`、`🌓 主题`、`❓ 帮助`——把现在散在左栏/参数栏的按钮收上来
- 左栏合并为一个「数据源」侧栏（目录树 + 文件列表**上下分布**，都是 200 px 宽），顶部 `‹` 按钮可整栏折叠
- 右侧参数栏保留，但加**折叠**（默认展开，"只看图"时一键收起 → 画布立刻 +285 px）
- 「操作」区合并：主按钮 + 导出菜单（§5.1）
- 状态栏右侧加"当前模式/样品数"徽标，进度条移到底部（少一个浮层）

*优点*：画布宽度 700 → 1000+ px；按钮数量减半；结构仍然熟悉。
*缺点*：`gui_ui.py` 的 `setup_ui` / `create_*_panel` 要重构，需要重跑全部回归 + 截图验收。

### 方案 C｜Dock 体系 + 设计系统（1–2 周，专业度最高）
- 三栏改 `QDockWidget`：可浮动、可停靠、可关闭，支持保存 2–3 套布局预设（"拟合工作台""出图工作台"）
- 引入统一的**线性图标集**（PNG/SVG，替换 emoji），配 `icons/` 资源目录
- 完整 design token + 三套主题（浅色 / 深色 / 高对比打印友好）
- 帮助改为独立窗口（左侧目录 + 右侧正文 + 搜索 + 复制）
- 空状态插画 + 首次使用引导（3 步）

*优点*：真正的"产品感"，也顺带解决 emoji 图标、帮助、可访问性。
*缺点*：改动面大，需要视觉回归基线，且短期会打断你现在的科研节奏。

> **我的建议**：先做 **方案 A**（1 天内）拿到"立刻变好看"的收益，再按 **方案 B** 分批推进；
> 方案 C 里的"图标集"和"帮助窗口"可以随时作为独立小任务插进来。

## 5. 视觉规范建议（design tokens）

### 5.1 按钮体系（收益最高的一改）

现在 7 种语义色全部以"实心大按钮"出现。建议改成：

| 角色 | 样式 | 用处 | 数量约束 |
|------|------|------|---------|
| `primary` | 实心 `ACCENT`，白字，加粗 | **当前模式的主操作**：光谱模式=实时预览，寿命模式=开始拟合 | 每屏 **1** 个 |
| `secondary` | 白底/卡片底 + 1 px `INPUT_BORDER` | 多数操作：选择文件夹、重新加载、导出当前图 | 不限 |
| `ghost` | 透明底，悬停浅底 | 工具栏图标按钮、目录树里的 🏠/🌙/❓ | 不限 |
| `danger` | 白底 + `#dc2626` 文字/描边 | 删除/清空类（暂无用例） | — |
| `menu` | secondary + 右侧 ▾ | 把多个导出合并：`💾 导出 ▾ → 当前图 / 全部图 / 拟合结果 / 汇总图 / PDF 报告` | — |

语义色改为**只做点缀**：
```css
QPushButton[variant="fit"]   { border-left: 3px solid VIOLET; }   /* 拟合类 */
QPushButton[variant="export"]{ border-left: 3px solid ORANGE; }   /* 导出类 */
```
配合 16×16 的单色图标（同一套线条风格），颜色信息保留、视觉噪音下降一个量级。

**操作区合并示例**（寿命模式，从 6 个按钮 → 1 主 + 2 次 + 1 菜单）：
```
[ ▶ 开始拟合 ]        ← primary（VIOLET 左边条 + 单色图标）
[ 📊 叠加分布 ]  [ 💾 导出 ▾ ]
                        ├ 当前拟合结果 (PNG + json)
                        ├ 跨样品汇总图
                        └ PDF 报告
```

### 5.2 字阶与密度

| 用途 | 现在 | 建议 | 说明 |
|------|------|------|------|
| 控件正文 | 15–16 px | **13 px** | 参数栏最挤，降 3 px 直接省出约 20% 高度 |
| 标签（`k_min` 等） | 16 px | **12 px** + `TEXT_SOFT` | 与数值框形成层级 |
| 组标题 | 16 px bold | **15 px** 600 字重 | 略降即可 |
| 辅助/提示 | 13 px | **11–12 px** `MUTED` | 保持可获得性 |
| 页面标题 | — | 20 px | 入口界面标题用 |

间距统一到 **4 的倍数**：卡片内边距 `12`、控件间距 `8`、区块间距 `16`、栏间距 `10`（现状 14/10/10/6 混用）。
实测预期：参数区内容高度 1963 px → **约 1450 px**（少滚 1 屏）。

### 5.3 截断与可读性
- 所有可能超长的 `QLabel`：`setTextElideMode` 不适用于 QLabel → 改用**中段省略**工具函数
  （`D:\北大\…\20260826RB.csv`）并**必定**带 `setToolTip(完整文本)`
- 下拉框：`setMinimumContentsLength(6)` 已有，但**必须保证选中项可见** → 给组合框单独放宽（参数栏允许 1–2 项更宽，或把单位移到标签行）
- 文件列表：`file_list.setToolTip` 跟随当前项 + 双击改名为"仅显示短名"，行高 24 px
- 新增 **搜索框**（`QLineEdit` + `setClearButtonEnabled(True)`）过滤文件列表，系列样品 A0…A24 直接用

### 5.4 层级与浮层
- 背景 `BG` → 卡片 `CARD` + 1 px `BORDER` + 10 px 圆角（现状 OK）
- 浮层（菜单/提示/进度）：`CARD` + 阴影（`QGraphicsDropShadowEffect`，blur 12、alpha 40）
- 禁止在同一屏出现 >2 种饱和色

## 6. 帮助面板重做（顺带解决"面板是浅色"的观感）

**现状**：`QMessageBox.about()` + 长富文本，实测 722×600 逻辑像素，占可用高度 70%；
不可滚动、不可复制、宽度不可调、再加内容就溢出。

**建议**：新写 `gui_help.py::HelpDialog(QDialog)`：
- 固定初始尺寸 **720×560**，可缩放，记忆大小
- 左侧 160 px **目录**（当前模式 / 快捷键 / 数据格式 / 导出 / 日志 / 关于），右侧 `QTextBrowser` 正文
- 顶部一行按钮：`📋 复制全部`、`📂 打开日志文件夹`、`🔍 搜索`（`QTextBrowser.find`）
- 样式完全走 `theme_palette()`，深色浅色一致；`QTextBrowser` 背景 = `CARD`
- F1 / 入口界面「？」共用同一个对话框（只是初始定位不同）
- 内容改为**结构化数据**（`HELP_SECTIONS = [(标题, HTML), ...]`），新增模块时不用再拼字符串

顺带优点：帮助内容以后可以随模式切换而**不重建窗口**，也不会再出现"帮助框把主窗口遮住 2/3"的情况。
