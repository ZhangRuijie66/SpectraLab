# 紧急说明：项目目录被「北大网盘 / AnyShare 同步盘」占位化，文件"看起来消失了"

**时间**：2026-09-10 19:00 前后
**受影响目录**：`D:\北大\光谱工具`（含 `可视化分析GUI`）

## 症状（实测）

- `画图` 目录对进程只剩 **1 个条目**（`可视化分析GUI`），`可视化分析GUI` 只剩 4 个
  （`tests` / `__pycache__` / `更新日志` / 3 字节的 `gui_ui.py`）；
  但 `Get-ChildItem -Recurse -Filter plot_lifetime.py` 又能"找到"这些文件——
  即**目录项还在、打开内容失败**，这是云盘"按需下载/释放空间"的典型表现。
- `Test-Path` / `Get-Item` / `cmd dir` / .NET `Directory.GetFileSystemEntries`
  四种方式结论一致（都看不到），排除工具差异。
- 期间还伴随：PowerShell 子进程 `spawn ENOENT`、`git` 报 not a repository、
  Edge 崩溃 `0x80000003`、以及本机 DSH 命令的 `workdir` 偶发失效。

## 根因（已定位）

`Get-CimInstance Win32_Service` 显示：

```
Name                 DisplayName              PathName
SyncClientService    AnyShare Family7 Service C:\Program Files (x86)\Bdwp\SyncDisk\SyncClientService.exe
```

`SyncDisk` 目录里有 `AnyShareClientSDK.dll` / `AnyShareClientUISDK.dll` ⇒
**北大网盘（AnyShare）的"同步盘"客户端**在管理这个目录，它会把文件转成
"联机可用/按需下载"的占位文件；本机现在**无法把这些占位文件重新落地**
（打开即报找不到），于是表现为"文件消失"。

`FileSyncHelper.exe` 属于 Microsoft OneDrive（只同步 `C:\Users\zhang\OneDrive`，与本目录无关）。
搜狗输入法（SogouCloud / SogouSvc）与本问题无关。

## 建议的恢复步骤（按优先级）

1. **打开北大网盘客户端**，找到这个同步目录 → 取消「按需下载 / 智能释放空间」，
   改为「**始终保留在此设备上**」，等它把文件全部下载回来；
   若之前执行过"释放空间"，文件在**云端**，客户端里下载即可。
   客户端里通常还有「**回收站 / 历史版本**」，可用来找回被删除或改坏的版本。
2. 登录**北大网盘网页版**，直接下载一份 `画图` 目录的副本（服务器侧一般有完整版本）。
3. **Windows「以前的版本」**：右键 `画图` 文件夹 → 属性 → 以前的版本
   （需要管理员权限；`vssadmin list shadows` 也要管理员）。
4. 恢复后请把本目录**移出同步盘**，或至少把该目录设为"始终保留"，
   否则同样的占位化还会再发生。

## 备忘：本机环境已知坑

- `同步到mac文件夹.ps1` / 打包脚本等 `.ps1` 必须保存为 **UTF-8 带 BOM**，
  否则 PowerShell 5.1 把中文读成乱码、整个脚本语法报错。
- 中文文件名用 `python 生成splash图.py` 直接调用时，argv 编码偶发错乱
  → 用 `tests\_diag\ascii_runner.py splash|vercheck|icons` 绕开
  （它用 `\u` 转义在 Python 内部拼文件名）。
