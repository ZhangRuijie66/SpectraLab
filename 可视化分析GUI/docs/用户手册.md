## 1. 这是什么

一个 Windows 桌面程序（PyQt5 + matplotlib），把实验室里四种常见的光谱数据
——**吸收、发射、荧光寿命、3D 扫描（EEM）**——读进来看图、处理、拟合、出图。

两种用法：

| 用法 | 入口 | 适用场景 |
|---|---|---|
| **便携 exe** | `便携版\光谱可视化分析工具.exe` | 目标电脑**不需要装 Python**，双击即用；U 盘拷走也能跑 |
| **源码运行** | `python start_gui.py` 或 `run_gui.bat` | 开发 / 改代码 |

单文件 exe 约 **103.2 MiB**；**首次启动要解压到临时目录并建字体缓存，实测 25–40 秒**
（第二次启动会快一些）。启动画面消失前**不要重复双击**。

## 5. 数据准备：格式与目录约定

### 5.1 目录约定（通用）

- 程序按**文件夹**加载：点「选择文件夹」（`Ctrl+O`）或把文件夹**拖到窗口上**。
- 只扫描该文件夹**第一层**的 `*.csv` / `*.txt`；**荧光寿命模式额外接受 `*.xlsx`**。
- 文件按**自然顺序**排序（`1, 2, …, 10, 11`，而不是 `1, 10, 11, 2`）。
- 目录里混着别的类型 CSV 是常态：解析不了的文件会被**静默跳过**，只有**全部失败**才弹警告。
- 「选择工作区」设置的是左侧**目录树**的根目录（自动记住，下次启动仍在）；点目录树里的
  子文件夹即可加载该文件夹。

### 5.2 可选：`说明.xlsx`（让图例显示浓度等信息）

在数据文件夹里放一个 `说明.xlsx`（首行列名），程序会自动读取并**把样品信息写进图例**：

| 编号 | RB浓度 | L8i浓度 | 备注 |
|---|---|---|---|
| 1 | 0 | 0 | 参比 |
| 2 | 20 | 200 | 样品 |

- 编号列名可以是 `编号` / `序号` / `No.`；其余非空列（`RB浓度`、`ZnPcS4浓度`、`Ce6浓度`、
  `备注`、`是否加入PVP` …）一律当作信息列。
- 程序用文件名里的数字去**容错匹配**编号（如 `20260827-1.csv` → 编号 1）；
  匹配不上就退回用文件名当图例。
- 读不到 `说明.xlsx` 不影响使用，只是图例用文件名。

### 5.3 各模式的数据格式

| 模式 | 格式 | 说明 |
|---|---|---|
| **吸收** | LabSolutions UV-Vis 导出的吸收光谱 CSV | 波长 / 吸光度两列（含表头自动跳过） |
| **发射** | ① Spectracle / FE30「发射数据组」CSV ② LabSolutions RF / RF-6000 Emission CSV ③ PerkinElmer FL WinLab 风格发射扫描 CSV（含 `Labels` / `Type` / `Fixed-Offset` / `XAxis` 字段） | 自动检测格式；自动提取 `EX WL` 等元信息；**激发光谱（Spectrum Type=Excitation）默认跳过** |
| **荧光寿命** | ① **Horiba / DeltaHub 时间扫描 CSV**：头部有 `Labels` / `Type` / `Start` / `Stop` / `Step`，数据区三列 `time, decay, irf`，行尾常有多余逗号 ② 简单三列表格 CSV/TXT ③ **多列 xlsx**（第一列时间 + 若干样品列 + IRF 列，自动按列拆分） | 数据区不足 3 列会明确报错：**没有 IRF 列就无法做重卷积拟合** |
| **3D 扫描** | Spectracle / FE30「3D 扫描」CSV | 头部含 `标签` / `EX WL 起点·结束` / `EX 读取间隔` / `EM WL 起点·结束` / `EM 读取间隔`；数据表头 `EM(nm)\EX(nm)`，**第一列是 EM 波长，其余每列是一个 EX 波长对应的强度** |

## 6. 模式一：吸收光谱 (UV-Vis)

1. 入口选 `吸收光谱 (UV-Vis)`，或把「光谱类型」切到该项。
2. 「选择文件夹」加载数据（或拖拽文件夹进来）。
3. 参数栏可用：
   - **图表类型**：`合并图 (Combined)`（所有曲线画一张）/ `单独图 (Single)`（每条一张）。
   - **绘图标题**：留空用默认标题。
   - **线宽**（默认 1.5，0.5–5.0）、**分辨率 DPI**（默认 600，72–1200）。
   - **标记峰**：自动找峰并标注；**峰位标数值 (nm)** 控制峰上是否写波长数字。
   - **峰检测参数**：峰高度阈值（默认 0.05，相对最大强度）、峰最小间距（默认 10 nm）。
   - **显示范围 (nm)**：波长上下限（加载后自动设为数据实际范围）。
   - **光谱减法**：选 A、B 两个文件画差谱 `A − B`；两者波长网格不齐时自动插值对齐并取重叠区间。
     A 选「所有光谱（各减本底）」则每条光谱都减去 B 本底。**样品与本底的波长范围没有重叠时
     无法相减**（例如 560–800 nm 的样品配 300–548 nm 的水本底）：这一条只跳过自己，其余光谱
     照常绘制与积分，状态栏会说明跳过了哪几条按什么原因。
   - **颜色方案**：默认 / 蓝-红 / 绿-紫 / 彩虹；**图例位置**：自动 / 四角 / 图外右上 / 图外下方 / 隐藏。
4. 左侧「数据」栏勾选要显示的曲线；点某个文件，右侧 `信息` 页显示它的详情
   （`信息` 页还会列出该样品在 `说明.xlsx` 里的变量，**空值一律不显示**）。
5. 下方「光谱积分（数据输出）」可对指定区间做积分，结果可直接复制（`Ctrl+D`）。
   积分只统计**左侧勾选的样品**（v4.37 起，与图上画出来的曲线一一对应）。
   某条光谱扣不了本底时会被跳过，计数标签会写「N 个无法扣本底已跳过」，
   把鼠标停在它上面可看是哪几条、为什么；一个都没勾时会提示
   「未勾选任何样品（积分只统计左侧勾选项）」。
6. **数据比较（v4.37）**：文件夹里有 `说明.xlsx` 时，参数栏多一个「数据比较」组，
   点「数据比较」按钮即在该标签页画「指标 - 变量」点线图（详见第 8 节）。

> 曲线颜色按**样品身份**分配并记忆：增删数据集时已有曲线的颜色不会变；
> 换文件夹才重新分配。

### 6.1 数据比较（吸收 / 发射通用，v4.37）

**前提**：数据文件夹里有 `说明.xlsx`（列名如 `编号 / RB浓度 / L8i浓度 / 备注`；
`编号` 列用于和文件名对号，匹配规则与图例增强相同）。

参数栏「**数据比较（说明.xlsx）**」组：

- **横轴变量**：`说明.xlsx` 里的某个**数值列**（如 `RB浓度`）。没有说明.xlsx、没有数值列、
  或那个 .xlsx 与文件名对不上编号时，按钮置灰，鼠标悬停可看具体原因。
- **分组变量（可选）**：再选一个数值列，每组画一条点线——例如横轴 `RB浓度`、
  按 `L8i浓度` 分组，就得到每个 L8i 浓度一条曲线。
- **纵轴指标**：
  - `峰强度`：区间内的最大强度（吸收模式显示为「最大吸收」）；
  - `峰面积`：区间积分，**默认复用下方「光谱积分」的起止波长**（两者用同一份实现，
    数字必然一致）；也可以在「峰强区间」里单独指定；
  - `指定波长处的值`：该波长处线性插值取值；落在数据范围之外**不外推**，直接跳过该样品。
- **峰强区间 / 指定波长**：只在与所选指标匹配时才可编辑（切指标会自动禁用无关输入框）。
- **数据比较**按钮：出图并自动切到「**数据比较**」标签页；
  **⤓ CSV** 把取点结果导出为 `样品, 编号, 横轴变量, 分组, 指标值`（UTF-8 BOM）。

**规则**：

- 只统计**左侧勾选**的样品；
- `说明.xlsx` 里该样品缺这个变量（空单元格、`null`、`N/A`、`-`、`—` 等文本空值）
  → **该样品不进入图**（不会出现 `nan` 点、也不补 0）；状态栏给出跳过条数，
  鼠标停在「数据比较」页上可看**是哪几条、为什么**（含「匹配不到编号」）；
- 数值 `0` 是有效值，不会被当成空；
- 「导出全部图片」会把这张点线图一起导出。

独立模块：`plot_compare.py`（可命令行直接用：`python plot_compare.py <文件夹> --list-vars`），
详见 `plot_compare使用说明.md`。

## 7. 模式二：发射光谱 (Emission)

在吸收模式的基础上多一个「**发射光谱选项**」组：

- **归一化强度**：把每条谱归一到最大值 1（对比峰形时常用）。
- **标注激发波长 (EX)**：在曲线旁标出 `EX = xxx nm`（从文件头自动提取）。

其他参数（图表类型、线宽、DPI、峰检测、显示范围、颜色、图例位置、积分）与吸收模式一致。
激发光谱会被自动跳过，所以同一文件夹里混着 EX/EM 数据也能直接用。
「数据比较」与吸收模式一致，只是纵轴措辞换成发射口径（峰强度 / 峰面积 /
指定波长处的发射强度），见 6.1 节。

## 8. 模式三：荧光寿命 (Lifetime)

这是功能最深的一个模式。**注意：寿命拟合很慢**——单文件 MEM 约 1–2 分钟，
勾选「自动拟合 λ」时约 2–4 分钟/文件。因此**加载文件夹不会自动开始拟合**，
必须点「⏱ 开始拟合」或「📊 实时预览」（两者等价，`F5` 也行）。

### 8.1 拟合方法：MEM / SESM

| 方法 | 全称 | 特点 |
|---|---|---|
| **MEM 最大熵（推荐）** | Maximum Entropy Method | 目标函数 `χ² − λ·S`，`S` 是熵正则；结果平滑、不需要预先假定分量个数，是默认选项 |
| **SESM 平滑指数** | Smooth Exponential / 快速模式 | 快得多，适合先看一眼大致分布 |

两者都做 **IRF 重卷积**，都需要数据里的 IRF 列。

### 8.2 寿命范围 τ_min / τ_max

- 拟合内部在**速率域**上做（`k = 1/τ`，单位 `1/ns`），但**面板上的输入是寿命 τ**
  （v4.38 起），不再要求用户自己换算速率；τ 的单位由 **8.2.1 的时间单位**决定。
- **速率网格点数**：默认 201（范围 51–401）。
- **寿命范围 τ_min / τ_max**：默认 `τ_min = 0.01 ns`、`τ_max = 100 ns`（ns 单位下），
  即 `k_min = 1/τ_max = 0.01`、`k_max = 1/τ_min = 100`（1/ns）。
- `τ_min` 是**最短**分量（对应最高速率 `k_max = 1/τ_min`），
  `τ_max` 是**最长**分量（对应最低速率 `k_min = 1/τ_max`）。
- **要拟合更长的寿命（μs 级）就把 τ_max 调大**（例如 `10000` ns = 10 μs）。
  反过来要分辨更短的寿命就调小 `τ_min`（最小 0.001 ns = 1 ps）。
- **两个框都不设上限**（唯一限制是 τ > 0，输入框的最大值 1e9 ns = 1 s 只是控件
  需要的有限值）：可以把 `τ_min` 设成 `20` ns 只看长寿命成分，
  也可以把 `τ_max` 设成 `1e6` ns（1 ms）。
- 两者必须满足 `τ_min < τ_max`：**谁被填到越界，另一个框会自动让路**
  （改动 `τ_max` → `τ_min` 退到 `τ_max/10`；改动 `τ_min` → `τ_max` 抬到 `τ_min×10`），
  状态栏会回显调整后的新范围。兜底逻辑（设置里存了坏值等极端情况）才会回退到
  默认的 0.01–100 ns，并给出提示。
- 信息页会回显本次实际使用的 `τ_max–τ_min`（并附对应的速率网格 `k`）。

#### 8.2.1 时间单位（ns / μs，全局设置）

- 「寿命拟合」组最上方有 **「时间单位: 纳秒 (ns) / 微秒 (μs)」** 下拉框，
  它是寿命模块的**全局设置**（所有文件共用，随会话记住，下次启动自动套用）。
- 它管的是**输入与显示**：`τ_min`、`τ_max`、`固定 τ` 都按所选单位填写；
  拟合图/诊断图的**时间轴**、寿命分布图的 τ 轴、信息页与分量表里的 τ 数值
  也按该单位显示（汇总图与 PDF 报告的 τ 与表头同样跟随）。
- 它**不改变任何计算**：内部一律按 ns 拟合，`k = 1/τ(ns)` 的速率网格、
  χ²R、分量个数与占比都与单位无关；结果 json 里的 `tau_*_ns` 永远以 ns 记录。
- **切换单位时输入框里的数值会自动换算**，物理范围保持不变：
  `100 ns` 在切到 μs 后显示为 `0.1 μs`；切回 ns 又变回 `100`。
  当前画布会用**已有拟合结果**按新单位重画（几十毫秒），**不会重新拟合**。
- 典型用法：1O2 磷光这类几十 μs 的样品，选「微秒」后 τ 范围写成
  `1` – `1000`（= 1 μs – 1 ms），不用再数 `1000` / `1000000` 这种 0。
- 「存为默认值」保存的 τ 范围与固定 τ **一律按 ns 存**，所以默认值的物理含义
  与显示单位无关——换单位不会让默认范围悄悄变 1000 倍。

### 8.3 熵权重 λ（手动 / 自动）

- λ 是 MEM 目标函数 `χ² − λ·S` 里的**熵正则强度**：
  **越大分布越平滑，越小越贴合噪声**。
- **手动**：滑块范围 `1e-6 – 1`（对数刻度），默认 `1e-3`。
- **自动拟合 λ（默认勾选，推荐）**：流程是
  `按当前 λ 拟合 MEM → 扫描 χ²R ≤ 1.1 的最大 λ → 用新 λ 重新拟合`。
  自动模式下 λ 输入框被禁用；信息页会显示扫描了多少个网格点、取了哪个 λ。
- 「自动拟合 λ」**每次启动都默认勾选**（不从上一次会话恢复），这是刻意设计。

### 8.4 固定寿命分量 τ

- 在「**固定 τ**」里填值，例如 `3.6` 或 `0.5, 3.6`（单位 ns，逗号分隔）。
- 填了就把这些 τ 作为**不受熵约束**的基函数一起拟合，**幅度自动求解**。
- 用途：扣除**参照染料寿命**、**IRF 拖尾**等已知分量，让 MEM 分布只描述样品本身的寿命。
- 留空 = 不固定。信息页会单列「固定分量（不受熵约束，幅度自动求解）」及其幅度。

### 8.5 拟合诊断页（标签页「拟合诊断」）

拟合完成后，该页画两张图，并配合 `信息` 页给出质量指标：

**上：IRF / 拟合区间诊断**
- `IRF（原始）` 与 `IRF（平移 qshift）` 两条曲线 —— 展示 IRF 平移了多少通道/ns。
- 衰减曲线 + **拟合区间**（程序自动确定 `fit_start`/`fit_end`，区间外的点不参与拟合）。

**下：残差自相关（ACF）**
- 残差的自相关柱状图，叠加 **±1.96/√N 的 95% 置信带**：
  落在带内 = 残差像白噪声（模型够用）；**lag 1 明显超出带外 = 残差有正相关（模型不足）**。

**信息页里的质量指标**（`— 拟合质量 —` 段）：

| 指标 | 含义 / 判读 |
|---|---|
| **χ²R** | 简化卡方。**本程序 χ²R 的分母是拟合点数 M，不是自由度 ν**（信息页会明确写「拟合点数 M = …（本程序的 χ²R 分母口径是 M，不是自由度 ν）」）。所以它不会恰好等于 1，**接近 1 就是好**；远大于 1 说明模型/区间/IRF 有问题 |
| **Durbin–Watson** | 残差自相关检验。< 1.5 → 提示「残差有正相关/模型不足」；否则「残差无明显自相关」 |
| **残差均值 / 标准差** | 均值应接近 0 |
| **残差自相关 lag1** | 与 95% 置信带 ±(1.96/√N) 一起看 |
| **皮尔逊残差 \|r\| > 3 的通道占比** | 离群通道比例，越小越好 |
| **IRF 位移 qshift / IRF FWHM** | IRF 平移量与半高宽 |
| **寿命范围 τ 与速率网格 k** | 回显本次实际使用的 `τ_max–τ_min`（ns）、对应速率 `k_min–k_max`、网格点数 |

### 8.6 寿命分布页与「强度占比」口径

- 标签页「**寿命分布**」显示 MEM 反演出的寿命分布曲线，以及从中分离出的
  **高斯分量**（对数 τ 轴）。
- `信息` 页的分量表：

  ```
  检测到 3 个寿命分量:
    τ1 = 3.62 ns, 占比 = 45.31%
    τ2 = 12.4 ns, 占比 = 38.02%
    ...
  ```

- **占比口径**：占比 = 该分量的**发光强度占比**（分布下的面积贡献，∝ 幅值/k
  的积分），不是峰高之比、也不是计数占比。程序对分布做峰分离后，按各分量的
  强度贡献归一化得到百分比。
- 「寿命分布」页图例还同时给出每个组分的**振幅占比**（峰高口径），与强度占比
  物理意义不同，见 8.8 节。
- 如果分布**过宽**、分不出明显峰，信息页会显示「未分离出明显寿命分量（分布过宽）」
  ——这时应当调小 λ（让分布更贴合数据）或调整 k 范围。

### 8.7 叠加寿命分布（并行拟合）

点「**📊 叠加寿命分布**」：

- 对**勾选的样品**并行拟合，把各文件的寿命分布**画在同一张图上**对比（v4.37 起
  只处理勾选项，以前是"全部已加载"）。
- **只画一部分样品**：在左侧「数据」栏取消勾选不想看的样品，再点「叠加分布」即可；
  一个都没勾时会提示先勾选。点某个文件名仍是单独拟合查看它（与勾选无关）。
- 这是「并行拟合」，比逐个点「开始拟合」快，但仍取决于文件数与是否自动拟合 λ。
- 适合比较一组样品的寿命分布形状差异。

**纵轴口径（v4.33 起）**：**不逐条归一**，所有曲线共用同一个比例因子
（全部曲线的全局最大值），因此曲线之间的高度差得以保留；旧行为把每条曲线
各自除以自身峰值、峰高全被拉到 1，只剩形状。

**图例只列样品名**（v4.34）：叠加图是"看形状对比"用的，逐条挂振幅/强度会把
图例撑成一大片、占掉右侧空间。**组分级的振幅与强度占比请到单独拟合的
「寿命分布」页看**（见 8.8 节）。

⚠ **含归一化输入时**：若某些文件是被归一化过（峰值 ≈ 1）的数据，程序会把它
各自还原到 1e4 刻度再拟合，各文件绝对刻度**不统一**，纵轴的绝对数值
**不可跨样品直接比较**（纵轴会自动附一行提示）。要让纵向可比，请让所有输入
处于同一计数刻度。

### 8.8 每个组分的振幅与强度占比（单独拟合）

单独点「开始拟合」后，「**寿命分布**」页图例对**每个分离出的组分**同时给出
两个占比：

```
τ₁ = 0.665 ns, 振幅 6.9%, 强度 1.5%
τ₂ = 2.96 ns, 振幅 100.0%, 强度 98.5%
```

同样两个占比也出现在两处（v4.35 起口径统一）：

- **`信息` 页的分量列表**：
  `τ1 = 0.6651 ns, 强度占比 = 1.54%，振幅占比 = 6.89%`
- **「拟合摘要」卡片的分量表**：4 列 —— 分量 / τ (ns) / **强度占比 (%)** /
  **振幅占比 (%)**，点表头可排序、框选可 Ctrl+C 复制。

| 记号 | 含义 | 口径 |
|---|---|---|
| **振幅占比** | 该高斯分量在 k 空间的**峰高**，按最大者归一为百分比 | 分布"**尖不尖**"。窄而快的伪分量峰可以很高 |
| **强度占比** | 该分量的**发光强度贡献**（分布下面积，∝ 幅值/k 的积分），各分量之和 = 100% | "这个组分是不是真正的**主发光体**" |

**为什么要两个都给**：两者物理意义不同、数值可以差很多。强度 ∝ 幅值/k 的积分，
所以**宽而慢**的分量强度大而峰不高；**窄而快**的分量峰高却几乎不发光
（多为上升沿形状失配的吸收器）。只看振幅会误判谁在发光，只看强度则看不出
分布是否被一个尖峰撑起来。

> 程序内部还会丢弃发光强度占比 < 0.5% 的"噪声分量"，所以图例里的组分都是
> 真正有贡献的；被丢弃的个数记在 `info['peaks_dropped_low_share']`。

### 8.9 寿命模式的完整操作流程

1. 模式切到 `荧光寿命 (Lifetime)`。
2. 选文件夹（`Ctrl+O` / 拖拽）→ 程序只做**解析**，不拟合；画布显示提示文字。
3. 左侧「数据」栏**勾选要拟合的文件**（单个文件最稳）。
4. 按需设置：拟合方法、速率网格点数、**时间单位（ns / μs）**、寿命范围 `τ_min/τ_max`、固定 τ、λ（自动/手动）。
5. 点「**⏱ 开始拟合**」或「📊 实时预览」（`F5`）→ 状态栏与进度条提示，等待 1–4 分钟。
6. 拟合完成：
   - `预览` 页：上=拟合曲线（log 纵轴，含平移后的 IRF），下=残差；
   - `寿命分布` 页：寿命分布 + 高斯分量；
   - `拟合诊断` 页：IRF/拟合区间 + 残差 ACF；
   - `信息` 页：全部数值指标与分量表。
7. 需要留档就点「💾 导出当前拟合结果」（见 [10.3](#103-导出当前拟合结果仅寿命模式)）。

### 8.10 把当前拟合参数存为默认值（💾 存为默认值）

- 在「寿命拟合」组里点「**💾 存为默认值**」，把当前这一组参数固定下来，
  **下次启动自动套用**：拟合方法、网格点数、`τ_min/τ_max`、固定 τ、
  λ 与「自动拟合 λ」勾选状态。
- 与「会话恢复」的区别：会话是**每次关窗自动覆盖**的；默认值**只有点这个按钮
  才更新**。所以临时试参数不会把默认值改掉，想改默认值就调好后**再点一次**。
- 存好后状态栏会回显一行摘要（例：`已存为默认值：MEM 最大熵 / 201 点 /
  τ 0.01–100 ns / λ 自动 / 固定 τ 无`）。
- 启动时的优先级：**存为默认值 > 上次会话 > 程序内置默认**。
  没有点过这个按钮时行为与以前完全一致。
- 注意：如果默认值里「自动拟合 λ」是勾选的，λ 输入框会像往常一样被禁用
  （自动模式下由程序扫描最优 λ）。

## 9. 模式四：3D 扫描 (EEM)

数据是**激发-发射矩阵**：横轴 EM 波长、纵轴 EX 波长、颜色/高度是强度。

### 9.1 三种绘图类型

| 选项 | 图形 | 适合 |
|---|---|---|
| **3D 曲面** | 带高度与颜色的曲面（默认视角 elev 25° / azim −60°） | 看整体峰形、论文封面图 |
| **等高线 (俯视图)** | 填充等高线（30 级） | 看峰位分布与轮廓，最省墨 |
| **Waterfall 堆叠谱** | 沿 EX 方向堆叠的发射谱（默认 10 条） | 看每个 EX 下的发射谱形状演变 |

点选文件即绘制（3D 扫描处理 < 1 秒，参数改动**自动重绘**，不需要像寿命那样显式触发）。

### 9.2 周期梳状伪迹与饱和的处理

原始 EEM 数据常有两类伪迹，直接插值只会把它们一起放大：

- **饱和点**：强度卡在仪器上限（例如 50000 反复出现，占全矩阵 10% 以上），
  在曲面上顶出一块平板；
- **窄线伪迹**：约 2 nm 宽、强度高 1–2 个数量级的固定 EM 尖刺
  （杂散光/级次光/光栅编码器跳变）。判据是**它们不随 EX 移动**，所以不是样品荧光。
  三次样条必须穿过这些点，于是在两侧振铃出负值 —— 视觉上就是「断开的尖刺」。

清洗顺序：`饱和掩膜 → 沿 EM 线性补全 → 中值去窄线 → 高斯平滑 → 三次样条加密显示`。

「**周期梳状伪迹处理**」下拉框的四个选项：

| 选项 | 内部模式 | 做法 | 代价 / 适用 |
|---|---|---|---|
| **只保留谷值通道**（默认） | `minima` | 找出周期条纹的**谷值通道**（唯一没被条纹抬高、也没饱和的样本），只留它们再插值重建 | **最稳**，是实测数据下的推荐值；代价是沿 EM 方向的有效采样点变少（分辨率略降） |
| **按乘性条纹除法** | `divide` | 把条纹当作乘性干涉 `Z_meas = I_true × gain(λ)`，估计增益后除掉（增益裁剪在 0.02–50） | 保留全部通道、分辨率最高；但**条纹峰值饱和时增益估不准**，容易把真信号一起除歪 |
| **污染整行替换** | `rows` | 判定被污染的 EM 通道行，沿 EM 用邻近干净行**线性插值整行替换** | 比频域相位法稳健（梳状相位会漂移）；代价是被替换行的真实结构（如果那行有窄峰）一并丢失 |
| **不处理** | — | 原样进入后续管线 | 仅用于**确认没有条纹**的数据 |

其它参数：

- **中值去窄线窗口**（默认 3，1–15）：中值滤波窗口，用来压掉 2 nm 级窄线伪迹；
- **EM 方向平滑 σ**（默认 1.0，0–5）、**EX 方向平滑 σ**（默认 0.0，0–5）：高斯平滑；
- **对数色标**：强度跨数量级时勾上更清楚。

颜色范围默认取**稳健分位数 1%–99.5%**，而不是数据极值 —— 否则色标被伪迹独占，
真正的发射带就看不见了。

## 12. 常见问题

### Q1 加载 0 个文件 / 提示「未找到CSV或TXT文件！」

- 检查文件夹里是否真有 `.csv` / `.txt`（**寿命模式**才额外认 `.xlsx`）。
- 程序只扫**第一层**，子目录里的文件不会自动加载 —— 请直接选那个子文件夹。
- 文件能列出但计数为 0：说明**解析全失败**（格式不符）。逐个格式对照
  [5.3](#53-各模式的数据格式)；寿命数据必须**至少 3 列**（time, decay, **irf**）。
- 目录里混着别的 CSV 属正常，会被静默跳过 —— 只要有一个能解析，计数就 > 0。

### Q2 χ²R 很大（比如 10、100）

先别怀疑拟合算法，按这个顺序查：

1. **IRF 是否选对/平移正确** —— 看「拟合诊断」页的 IRF 平移量与 IRF FWHM 是否合理；
2. **拟合区间是否合适** —— 区间里若混进 IRF 上升沿或长尾噪声，χ²R 会被拉高；
3. **寿命范围是否覆盖真实寿命** —— 真实 τ 落在 `τ_min–τ_max` 之外时，模型无论如何都拟合不好；
   （这两个框就是面板上的 `τ_min / τ_max`，对应速率 `k_max = 1/τ_min`、`k_min = 1/τ_max`）
4. **λ 是否太大** —— 熵正则过强会把分布压平、贴不上数据；试试调小 λ 或让「自动拟合 λ」自己找；
5. **有没有饱和/窄线伪迹** —— 寿命数据也可能带尖刺；
6. **记住 χ²R 的口径**：本程序分母是**点数 M**，不是自由度 ν，所以它**不会正好等于 1**。
   配合「残差自相关 lag1 是否在 ±1.96/√N 带内」「Durbin–Watson 是否 ≥1.5」一起判断更可靠。

### Q3 寿命占比之和不为 1（100%）

- 占比是**分布面积**归一化的结果，而分量是从分布里**峰分离**出来的。
  当分布很宽、峰互相重叠、或尾部被截断（τ 范围不够）时，
  被识别出的峰面积之和自然不到 100% —— 剩下的面积属于「没被分成峰的连续分布」。
- 处理：缩小 λ 让分布更贴合、扩大寿命范围（尤其把 `τ_max` 调大以覆盖长寿命尾巴），
  或接受「宽分布」这个事实（信息页会提示「未分离出明显寿命分量（分布过宽）」）。
- 如果**固定寿命分量**也参与了拟合，它们不在百分比里 —— 它们单列幅度（counts）。

### Q4 3D 图有负值 / 出现条纹

- **负值**：多由**窄线伪迹**引起 —— 三次样条必须穿过那些尖刺，于是在两侧振铃出负值。
  处理：确认「中值去窄线窗口」≥3（默认 3），必要时加大到 5；
  若条纹是周期性的，选「只保留谷值通道」（默认）或「污染整行替换」。
- **条纹**：EEM 数据里 ~7 nm 周期的固定 EM 条纹（等厚干涉/光栅鬼线）。
  位置固定在 EM、峰值常饱和。
  - 默认「只保留谷值通道」最稳；
  - 「按乘性条纹除法」保留分辨率但怕饱和；
  - 若数据**本来就没有条纹**，请选「不处理」，否则会白白损失信息。
- **色标被一小块亮斑独占**：颜色范围已默认取 1%–99.5% 分位；仍不理想可勾「对数色标」。
- **图看着像平板**：检查是否有**饱和点**（强度卡在某个上限反复出现），
  饱和掩膜是自动的，但饱和值占比过高时效果有限，需要原始数据重新采集。

### Q5 首次启动很慢 / 启动画面卡住

- 单文件 exe 首次启动要解压到临时目录并建字体缓存，**25–40 秒属正常**；
  启动画面消失前**不要重复双击**（会开多个实例）。
- 源码启动没有这个问题。

### Q6 中文显示成方框

- 确认系统有微软雅黑（Windows 默认有）；exe 首次启动建字体缓存需要时间。
- 若在非中文 Windows 上运行，程序会按平台回退字体（macOS 用 PingFang SC，
  Linux 用 Noto Sans CJK SC）。

### Q7 深色主题下参数面板还是白底

- v4.20 已知问题：参数栏的滚动区视口与「光谱积分」结果框未被 QSS 完全覆盖，
  深色下仍是白底黑字（**不影响读数**）。已在 `更新日志\CHANGELOG_v420.md` 记录。

## v4.22 新增（全局拟合 / 散射剥离 / 汇总图 / PDF 报告）

### 荧光寿命：全局拟合

两个新函数（GUI 目前通过脚本调用；命令行同 `plot_lifetime` 模块）：

| 函数 | 模型 | 适用场景 |
|---|---|---|
| `fit_global(datasets)` | 所有数据集**共享一份速率分布**，各自只有幅度 | 同一样品的重复测量 / 多检测窗 |
| `fit_global_discrete(datasets, n_comp=3)` | **共享 n 个寿命 τ**，各样品独立解幅度 | 滴定/系列样品（FRET A0→A24） |

实测：合成双指数两数据集 → Σχ²R=2.13，τ=2.468/7.927 ns；
7 份 FRET 数据（n_comp=3）→ 共享 τ=0.735/2.018/3.521 ns，Σχ²R=17.8。

> 提示：全局拟合的基函数必须"先卷积 IRF、后按 qshift 平移"，否则大位移时
> χ²R 会从 3.7 恶化到 285（模块内部已修正）。

### 荧光寿命：两个新按钮（寿命模式专属）

- **📈 跨样品汇总图**：并行拟合当前文件夹全部文件，画三联图
  （τ_i / α_i / χ²R 随样品变化），适合直接看滴定趋势；
- **📄 导出 PDF 报告**：第 1 页汇总表 + χ²R 柱状图，之后每个样品一页
  （衰减+拟合+IRF+寿命分布+残差统计）。

### 3D 扫描：散射剥离与定量校正

  实测对角线区均值 982 → 330，非散射区逐点零改动；
- **空白扣除**：`prepare_grid(blank=空白数据)` 做 Z − Z_blank（网格须一致）；
- **内滤校正**：`inner_filter_correction(data, a_ex, a_em)` →
  `F_corr = F_obs·10^((A_ex+A_em)/2)`。
