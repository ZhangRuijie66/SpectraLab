# 🚀 GUI程序启动说明

## ✅ 推荐启动方法

### 方法1：批处理文件（已修复）
```
双击：run_gui.bat
```

**说明**：修复后的版本使用 `start_gui.py` 启动，窗口会保持在最前面。

### 方法2：Python脚本（最可靠）
```bash
cd "D:\北大\光谱工具"
python start_gui.py
```

**说明**：这个方法最可靠，窗口会强制显示在最前面。

## 📱 使用步骤

### 第1步：启动程序
- 双击 `run_gui.bat` 或运行 `python start_gui.py`

### 第2步：查看窗口
- 窗口标题：**"吸收光谱可视化分析工具 v1.0"**
- 如果没看到，按 `Alt+Tab` 切换窗口

### 第3步：加载数据
1. 点击左侧的 **"选择文件夹"** 按钮
2. 选择数据文件夹，例如：
   ```
   D:\北大\QLS Lab\SPC\1O2+luminol\谱图\光谱\20260826
   ```
3. 等待文件加载完成

### 第4步：使用程序
- 点击 **"实时预览"** 查看图表
- 调整参数（线宽、颜色、DPI等）
- 点击 **"导出图片"** 保存结果

## 🎯 窗口识别

### 窗口标题
```
吸收光谱可视化分析工具 v1.0
```

### 任务栏图标
- 在Windows任务栏底部寻找此图标
- 图标通常是Python或PyQt的默认图标

### 如果找不到窗口
1. 按 `Alt+Tab` 查看所有打开的窗口
2. 按 `Win+Tab` 查看任务视图
3. 检查是否有最小化的窗口

## ❓ 常见问题

### Q: 双击run_gui.bat后没有窗口？
A: 窗口可能打开在后台，按 `Alt+Tab` 切换到它。

### Q: 如何确认程序是否在运行？
A: 查看任务管理器，寻找 `python.exe` 或 `absorption_gui.py` 进程。

### Q: 窗口标题是什么？
A: "吸收光谱可视化分析工具 v1.0"

### Q: 程序是否支持多开？
A: 可以同时运行多个实例，但建议一次只运行一个。

### Q: 如何完全退出程序？
A: 点击窗口右上角的 X 按钮，或使用文件菜单中的退出选项。
