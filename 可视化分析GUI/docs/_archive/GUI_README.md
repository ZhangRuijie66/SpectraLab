# 吸收光谱可视化分析工具 (GUI)

一个基于PyQt5的交互式吸收光谱分析和可视化工具。

## 功能特点

### 🎯 核心功能
- **文件/文件夹选择器**：轻松选择数据文件夹，自动加载CSV/TXT文件
- **参数调整面板**：实时调整线宽、DPI、颜色方案等绘图参数
- **实时预览**：参数修改后立即看到效果
- **导出图片功能**：支持PNG、PDF、SVG格式
- **数据缓存机制**：数据加载后保持在内存中，切换快速流畅

### 📊 图表类型
1. **合并图 (Combined)**：在一张图上显示所有光谱曲线，便于对比
2. **单独图 (Single)**：单独显示每个文件的光谱，适合详细分析

### 🔧 可调参数
- **线宽**：0.5 - 5.0
- **分辨率 (DPI)**：72 - 600
- **峰检测**：
  - 峰高度阈值：0.01 - 1.0
  - 峰最小间距：5 - 50 nm
- **颜色方案**：
  - 默认 (Default)
  - 蓝-红 (Blue-Red)
  - 绿-紫 (Green-Purple)
  - 彩虹 (Rainbow)
- **图表尺寸**：自定义宽度和高度

## 操作指南

### 1. 加载数据
1. 点击 **"选择文件夹"** 按钮
2. 选择包含CSV/TXT数据文件的文件夹
3. 程序会自动加载所有支持的文件

### 2. 查看文件列表
- 左侧列表显示所有已加载的文件
- 点击文件名可查看详细信息

### 3. 调整绘图参数
- **图表类型**：选择"合并图"或"单独图"
- **线宽**：调整曲线粗细
- **DPI**：调整输出图片分辨率
- **标记峰**：勾选以自动标记吸收峰
- **峰检测参数**：调整峰检测的敏感度
- **颜色方案**：选择喜欢的颜色风格
- **图表尺寸**：调整图表大小

### 4. 实时预览
- 调整参数后点击 **"📊 实时预览"** 按钮
- 预览会显示在右侧画布区域

### 5. 导出图片
- **导出当前图表**：点击 **"💾 导出图片"** 保存当前预览
- **导出全部图片**：点击 **"📁 导出全部图片"** 批量导出所有单独图和合并图

### 6. 查看信息
- 点击 **"信息"** 标签页查看文件详细信息
- 包括波长范围、数据点数、吸收值范围、峰信息等

## 数据格式支持

### 支持的文件格式
- CSV文件 (*.csv)
- TXT文件 (*.txt)

### 支持的数据格式

**吸收光谱（UV-Vis）**
1. **标准格式**：
   ```
   波长(nm),吸收值
   700,0.0234
   699,0.0245
   ...
   ```
2. **LabSolutions UV-Vis格式**：
   - 自动识别并解析元数据
   - 自动反转波长顺序（如果是从大到小）

**发射光谱（Emission）**（复用 `plot_emission` 模块，格式自动检测）
1. **Spectracle / FE30 格式**（含"发射数据组"、"波长(nm)"等中文字段）
2. **LabSolutions RF / RF-6000 格式**（含 Sample Name、EX Wavelength、Spectrum Type）
3. **PerkinElmer FL WinLab 风格**（纯英文、无中文表头，如 `EmScan1.csv`）：
   - 元数据块为 `Labels,<名称>,` / `Type,Emission Scan,` / `Start`/`Stop`/`Step` /
     `Fixed/Offset,<波长>,` / `XAxis,Wavelength` / `YAxis,Counts`
   - 空行后为数据块 `<波长>,<强度>,`
   - 自动提取标签（Labels）与激发波长（Fixed/Offset）作为 EX WL

## 高级功能

### 峰检测
程序使用 `scipy.signal.find_peaks` 进行峰检测：
- 自动检测吸收峰位置和强度
- 可调整检测阈值和最小间距
- 在合并图和单独图中都可以标记

### 数据缓存
- 数据加载后保存在内存中
- 切换文件无需重新加载
- 点击 **"重新加载数据"** 可重新加载当前文件夹

### 📋 说明.xlsx 信息自动写入图例
- 选择数据文件夹后，程序自动读取该文件夹下的 **`说明.xlsx`**（若无则忽略）。
- 自动识别「编号」列与其余信息列（`ZnPcS4浓度` / `RB浓度` / `L8i浓度` /
  `Ce6浓度` / `CPC浓度` / `是否加入PVP` / `备注` 等），无需手动配置。
- 图例标签按编号自动增强，例如：
  - `ce6-7（Ce6浓度=100, L8i浓度=1000, 是否加入PVP=是）`
  - 文件名本身就是编号时显示为 `#1 RB浓度=10, L8i浓度=1000, 备注=参比`
- 匹配不到编号时回退到原文件名，不影响绘图。
- 底层封装在 **`read_xlsx_info.py`**，可在任意脚本中独立调用。

### 多线程绘图
- 使用后台线程进行绘图
- 避免界面卡顿
- 显示进度条和状态信息

## 常见问题

### Q: 程序无法启动？
A: 请确保已安装所有依赖：
```bash
pip install PyQt5 matplotlib numpy scipy pandas
```

### Q: 找不到数据文件？
A: 请检查：
1. 文件格式是否为CSV或TXT
2. 文件是否在正确的文件夹中
3. 文件是否包含有效的波长和吸收值数据

### Q: 图表显示异常？
A: 尝试：
1. 点击"重新加载数据"
2. 调整绘图参数
3. 检查数据文件格式是否正确

### Q: 导出图片失败？
A: 请检查：
1. 是否有写入权限
2. 磁盘空间是否充足
3. 文件名是否包含非法字符

### Q: 程序运行缓慢？
A: 如果数据文件很多：
1. 减少每次加载的文件数量
2. 调低DPI设置
3. 关闭峰检测功能
