## 🎮 快速使用

### 第1步：加载数据
1. 点击左侧的 **"选择文件夹"** 按钮
2. 选择数据文件夹，例如：
   ```
   D:\北大\QLS Lab\SPC\1O2+luminol\谱图\光谱\20260826
   ```
3. 等待文件加载完成（左侧列表会显示CSV文件）

### 第2步：查看预览
1. 点击 **"📊 实时预览"** 按钮
2. 右侧画布会显示吸收光谱图

### 第3步：调整参数
- **图表类型**：切换合并图/单独图
- **线宽**：调整曲线粗细
- **DPI**：调整输出分辨率
- **标记峰**：勾选以标记吸收峰
- **颜色方案**：选择喜欢的颜色

### 第4步：导出图片
- 点击 **"💾 导出图片"** 保存当前预览
- 点击 **"📁 导出全部图片"** 批量导出所有图片
