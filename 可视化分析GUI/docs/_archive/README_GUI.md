## 🚀 快速开始（3步）

### 第1步：安装依赖
```bash
pip install PyQt5
```
或使用国内镜像（更快）：
```bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple PyQt5
```

### 第2步：验证安装
```bash
python check_dependencies.py
```

### 第3步：启动程序
```bash
# Windows用户
双击 run_gui.bat

# 或命令行
python absorption_gui.py
```

## 🎓 使用示例

### 示例1：快速查看数据
```
1. 启动程序
2. 点击"选择文件夹"
3. 选择 20260826 文件夹

```

### 示例2：对比多个光谱
```
1. 加载数据
2. 切换到"合并图"
3. 选择"彩虹"颜色方案
4. 点击"实时预览"
5. 点击"导出图片"保存

### 示例3：详细分析单个光谱
```

2. 切换到"单独图"

5. 点击"实时预览"
6. 查看"信息"标签页
```

### 示例4：批量导出

2. 调整参数到满意的效果

4. 选择保存位置
5. 等待完成！
```

## 🔧 问题排查

### 问题：程序无法启动
```bash
# 检查依赖
python check_dependencies.py

# 如果PyQt5未安装
pip install PyQt5
```

### 问题：找不到文件
- 确保选择包含CSV/TXT文件的文件夹
- 不要选择子文件夹

### 问题：图表显示异常
- 点击"重新加载数据"
- 检查文件格式
- 查看状态栏错误信息
