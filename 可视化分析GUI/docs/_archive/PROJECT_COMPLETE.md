### 快速启动（3步）

#### 第1步：安装依赖
```bash
pip install PyQt5
```
**状态**：✅ 已安装（PyQt5 5.15.11）

#### 第2步：启动程序
```bash
# 方法1：双击批处理文件
双击：run_gui.bat

# 方法2：命令行
cd "D:\北大\QLS Lab\SPC\1O2+luminol\谱图\光谱\画图"
python absorption_gui.py
```

#### 第3步：使用程序
1. 点击"选择文件夹"，加载数据
2. 调整参数，点击"实时预览"
3. 点击"导出图片"保存结果

### 基础操作流程
```
选择文件夹 → 等待加载 → 实时预览 → 调整参数 → 导出图片
```
