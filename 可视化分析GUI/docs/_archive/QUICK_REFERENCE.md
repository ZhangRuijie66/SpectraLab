# 快速参考卡片

## 一键启动
```bash
python absorption_gui.py
```

## 基础操作流程
```
选择文件夹 → 等待加载 → 实时预览 → 调整参数 → 导出图片
```

## 推荐参数设置

### 快速预览
```
线宽: 1.0
DPI: 100
标记峰: ✗
图表: 6×4
```

### 常规使用
```
线宽: 1.5
DPI: 200
标记峰: ✓
峰高阈值: 0.05
图表: 8×5
```

### 高质量输出
```
线宽: 2.0
DPI: 300
标记峰: ✓
峰高阈值: 0.1
峰间距: 20
颜色: 彩虹
图表: 10×6
```

## 快捷操作

### 查看单个光谱
1. 切换到"单独图"
2. 点击文件列表中的文件
3. 点击"实时预览"

### 对比多个光谱
1. 切换到"合并图"
2. 选择"彩虹"颜色方案
3. 点击"实时预览"

### 批量导出
1. 加载完数据
2. 点击"导出全部图片"
3. 选择保存位置

## 常见问题速查

| 问题 | 解决方案 |
|------|---------|
| 无法启动 | 安装PyQt5 |
| 找不到文件 | 检查文件夹选择 |
| 显示异常 | 重新加载数据 |
| 导出失败 | 检查写入权限 |
| 运行缓慢 | 减少文件数 |

## 颜色方案
- **Default** - 默认蓝红
- **Blue-Red** - 蓝色到红色渐变
- **Green-Purple** - 绿色到紫色渐变
- **Rainbow** - 彩虹色（推荐对比使用）

## 峰检测参数
- **峰高度阈值**：0.01-1.0（越小越敏感）
- **峰最小间距**：5-50 nm（越大过滤越严格）

## 支持的文件格式
- CSV文件 (*.csv)
- TXT文件 (*.txt)

## 导出格式
- PNG（推荐）
- PDF（印刷）
- SVG（矢量图）
