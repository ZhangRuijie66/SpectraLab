# 快速启动指南

## 一分钟快速开始

### 1️⃣ 安装依赖（只需一次）
```bash
python install_dependencies.py
```
或手动安装：
```bash
pip install PyQt5 matplotlib numpy scipy pandas
```

### 2️⃣ 启动程序
**Windows用户**：双击 `run_gui.bat`

**命令行**：
```bash
python absorption_gui.py
```

### 3️⃣ 使用步骤
1. 点击"选择文件夹"，选择数据文件夹（如 `20260826`）
2. 等待文件加载完成
3. 点击"实时预览"查看图表
4. 调整参数（线宽、颜色等）
5. 点击"导出图片"保存结果

## 常见操作

### 查看单个光谱
1. 切换到"单独图 (Single)"模式
2. 在左侧文件列表中点击要查看的文件
3. 点击"实时预览"

### 对比多个光谱
1. 切换到"合并图 (Combined)"模式
2. 调整颜色方案让曲线更清晰
3. 点击"实时预览"

### 标记吸收峰
1. 勾选"标记吸收峰"
2. 调整"峰高度阈值"和"峰最小间距"
3. 点击"实时预览"

### 批量导出
1. 加载完所有数据后
2. 点击"导出全部图片"
3. 选择保存位置
4. 所有图片自动保存到 `plots/` 文件夹

## 参数建议

### 初学者建议设置
- 线宽：1.5
- DPI：200
- 标记峰：✓
- 峰高度阈值：0.05
- 峰最小间距：10

### 高质量输出
- 线宽：2.0
- DPI：300
- 颜色方案：彩虹
- 图表宽度：10
- 图表高度：6

### 快速预览
- 线宽：1.0
- DPI：100
- 标记峰：✗

## 问题排查

### 程序启动失败
```bash
# 检查Python版本（需要3.7+）
python --version

# 检查依赖
python -c "import PyQt5, matplotlib, numpy, scipy, pandas"
```

### 找不到文件
确保选择包含CSV/TXT文件的文件夹，而不是子文件夹。

### 图表显示异常
1. 点击"重新加载数据"
2. 检查文件格式是否正确
3. 查看控制台错误信息

## 测试数据
