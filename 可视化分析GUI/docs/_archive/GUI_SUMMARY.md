## 🚀 使用方法

### 安装依赖
```bash
pip install PyQt5 matplotlib numpy scipy pandas
```

### 启动程序
```bash
# Windows
双击 run_gui.bat

# 命令行
python absorption_gui.py
```

### 基本操作
1. 选择文件夹加载数据
2. 调整参数（线宽、颜色等）
3. 点击"实时预览"查看效果
4. 点击"导出图片"保存结果
