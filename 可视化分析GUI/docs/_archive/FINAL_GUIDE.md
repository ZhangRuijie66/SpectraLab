## 🎯 快速使用（3步）

### 第1步：加载数据
1. 点击 **"选择文件夹"** 按钮
2. 选择数据文件夹，例如：
   ```
   D:\北大\光谱工具\示例数据\测试数据\20260826
   ```
3. 等待文件加载完成

### 第2步：查看预览
1. 点击 **"📊 实时预览"** 按钮
2. 右侧画布会显示吸收光谱图

### 第3步：导出图片
1. 调整参数到满意的效果
2. 点击 **"💾 导出图片"** 或 **"📁 导出全部图片"**
3. 选择保存位置
