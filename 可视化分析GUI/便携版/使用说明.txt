================================================

  构建日期 : 2026-09-09

             入口界面的版本徽标与标题栏「？」帮助里也会显示版本号、更新日期与创建人。

【这是什么】
  这是一个独立的可执行程序（.exe），已把 Python 环境和所有依赖库
  （PyQt5 / matplotlib / scipy / pandas / numpy / openpyxl 等）一起打包进去。
  目标电脑【无需安装 Python】，双击即可使用；拷到 U 盘 / 其它 Windows 电脑同样能跑。


【使用方法】
  1. 双击「光谱可视化分析工具.exe」。
     首次启动会解压到系统临时目录并建立字体缓存，**实测需要 25–40 秒**，属正常现象；
     启动画面消失前请勿重复双击（会同时开多个实例）。
  2. 启动后先弹出「选择模块」对话框，四张卡片对应四个功能模式：
       吸收光谱 (UV-Vis) —— 紫外-可见吸收光谱绘图与峰标注
       发射光谱 (Emission) —— 荧光发射光谱绘图、EX 标注与归一化
       荧光寿命 (Lifetime) —— 最大熵寿命拟合（MEM/SESM）与分量分解
       3D 扫描 (EEM) —— 激发-发射矩阵曲面/等高线/Waterfall，自动去周期梳状伪迹
     点卡片进入主窗口；主窗口左上角的「光谱类型」下拉框可随时换模式，
     「🏠 返回模块选择」可以退回这个对话框。
  3. 加载数据：
       - 点左上「选择工作区」设置目录树的根目录（会自动记住，下次启动仍有效）；
       - 点左侧目录树的某个子文件夹，或点「选择文件夹」；
       - 也可以直接把文件夹**拖到窗口上**。
     程序只读该文件夹第一层的 .csv / .txt（荧光寿命模式额外支持 .xlsx），
     能解析的文件进入左侧「数据」列表，勾选即绘图。
  4. 右侧画布上方有「预览 / 寿命分布 / 拟合诊断 / 信息」标签页
     （后两个标签页只在荧光寿命模式下出现）；
     画布自带缩放 / 平移 / 重置工具条。


【四个模式怎么用（要点）】
  · 吸收 / 发射：勾选文件即出图；可调图表类型（合并图 / 单独图）、线宽、DPI、
    标记峰、峰检测阈值、显示范围、颜色方案、图例位置。
    发射模式额外支持「归一化强度」与「标注激发波长 (EX)」。
    数据文件夹里放一个 说明.xlsx（含「编号」列 + 浓度/备注等列），
    程序会自动把样品信息写进图例。

  · 荧光寿命：**拟合很慢**（单文件 MEM 约 1–2 分钟；勾选「自动拟合 λ」约 2–4 分钟/文件），
    所以加载文件夹后不会自动算，必须点「⏱ 开始拟合」或「📊 实时预览」（快捷键 F5）。
       - 拟合方法：MEM 最大熵（推荐，结果平滑、无需预设分量个数）/ SESM（快，先看个大概）；
       - 速率网格 k（k = 1/τ，单位 1/ns）：默认 k_min 0.01、k_max 100，对应 τ = 100 ns–10 ps；
         要拟合更长的寿命（μs 级）请把 k_min 调小；
       - 熵权重 λ：越大分布越平滑、越小越贴合噪声；勾选「自动拟合 λ」（默认勾选）
         会自动扫描 χ²R ≤ 1.1 的最大 λ 再重拟合；
       - 固定寿命分量 τ：填 3.6 或 0.5, 3.6 等，把这些 τ 作为不受熵约束的基函数一起拟合，
         用于扣除参照染料寿命、IRF 拖尾等已知分量；
       - 拟合完成后：「拟合诊断」页看 IRF 平移 / 拟合区间 / 残差自相关（含 ±1.96/√N 置信带、
         Durbin–Watson）；「信息」页给出 χ²R、λ、分量 τ 与占比、质量指标。
         注意：本程序 χ²R 的分母是拟合点数 M（不是自由度 ν），所以不会正好等于 1，接近 1 即好。
       - 「📊 叠加寿命分布（并行拟合全部）」可把多个文件的寿命分布画在一张图上对比。

  · 3D 扫描 (EEM)：点选文件即绘制（处理很快，改参数自动重绘）。
       - 绘图类型：3D 曲面 / 等高线（俯视图）/ Waterfall 堆叠谱；
       - 「周期梳状伪迹处理」四选一：
           只保留谷值通道（默认，最稳）/ 按乘性条纹除法（分辨率高但怕饱和）/
           污染整行替换 / 不处理（数据本来没条纹时选它）；
       - 还可调中值去窄线窗口、EM/EX 方向平滑 σ、对数色标。
       详细说明见程序目录里的 docs\用户手册.md（源码目录）。


【导出】
  · 图片格式（参数栏「导出格式」）：PNG（位图）/ PDF（矢量）/ SVG（矢量），
    以及 PNG+PDF、PNG+SVG、全部三种的组合。分辨率默认 600 DPI（可调 72–1200）。
  · 「💾 导出图片」导出当前画布；「📁 导出全部图片」批量导出。
  · 「出版图预设」一键切换出图尺寸：单栏 3.5 in / 双栏 7 in / 幻灯片 10×6。
  · 荧光寿命模式下还有「💾 导出当前拟合结果」：输出汇总表
    lifetime_fit_results_summary.csv / .xlsx，以及每个文件一份
    lifetime_fit_results_<文件名>_report.md 报告。
  · 画布下方「光谱积分（数据输出）」的结果可直接复制（快捷键 Ctrl+D）。


【界面与快捷键】
  · 深色主题：左上角「🌙 深色主题」按钮一键切换（切回后显示「☀️ 浅色主题」）。
    提示：深色主题下导出的图片也是深底，出论文图请先切回浅色主题再导出。
  · 会话恢复：关闭程序时自动记住上次的模式、文件夹、窗口大小位置与常用参数，
    下次启动自动恢复（「自动拟合 λ」每次启动都默认勾选，不恢复）。
  · 最近文件夹：下拉框保留最近 6 个文件夹，选中即加载。
  · 快捷键：
       F5            实时预览（荧光寿命模式下 = 开始拟合）
       Ctrl+R        重新加载数据
       Ctrl+O        选择文件夹
       Ctrl+E        导出图片
       Ctrl+Shift+E  导出全部图片
       Ctrl+D        复制积分结果
       F1            帮助（含快捷键清单）


【注意事项】
  · 首次启动 25–40 秒属正常；之后启动会快一些。
  · 关闭程序时若提示「工作区已切换」，说明工作区已记住，下次启动自动定位到该目录。
  · 如被 360 / Windows Defender 等安全软件误拦截，请选择「允许运行」；
    exe 为 PyInstaller 正常打包产物，加入白名单即可。
  · 系统建议：Windows 10 / 11（x64）。
  · 已知小问题（v4.20）：深色主题下参数面板与积分结果框仍是白底黑字（不影响读数）。
  · 加载 0 个文件：确认文件夹里确实有 .csv/.txt（寿命模式才认 .xlsx），
    且文件在**第一层**（不会递归子目录）；寿命数据必须至少 3 列（time, decay, irf）。


【重新打包】
  如需重新打包，在源码目录执行（需要 Python 3.11 + 依赖，见 requirements.txt）：
