# 示例数据

从真实测量数据中挑选的示例集，用于验证各绘图模式能否正常工作。
**本目录只是各绘图模式的示例集，原始测量记录不在仓库内**，改动这里不影响原始记录。

| 目录 | 模式 | 数据来源 | 文件数 |
|---|---|---|---|
| `01-吸收-UVVis-RB与R101` | 吸收 | `SPC\1O2+luminol\谱图\光谱\202609\20260915ab` | 3 |
| `02-发射-RF6000-RB与R101` | 发射 | `SPC\1O2+luminol\谱图\光谱\202609\20260915` | 6 |
| `03-荧光寿命-Ce6` | 荧光寿命 | `SPC\1O2+luminol\谱图\光谱\202609\20260922lifetime` | 1 |
| `04-3D扫描EEM-RB-Lu` | 3D 扫描 | `SPC\1O2+luminol\谱图\光谱\202607\20260727-RB-Lu` | 1 |
| `05-数据比较-浓度梯度` | 数据比较 | `SPC\1O2+luminol\谱图\光谱\202610\20261010` | 28 |

## 各目录用途

### 01-吸收-UVVis-RB与R101
LabSolutions UV-Vis 吸收光谱，3 条：RB（罗丹明B）、R101（罗丹明101）两份。
用于「吸收」模式的单谱与归一化对比。

### 02-发射-RF6000-RB与R101
LabSolutions RF-6000 发射光谱，6 条，激发波长 550 nm：RB、R101 各两次测量 + EtOH / H2O 溶剂空白。
用于「发射」模式；空白谱可用来演示溶剂背景扣除。

### 03-荧光寿命-Ce6
Horiba/DeltaHub 时间扫描 CSV（`time / decay / irf` 三列），Ce6 染料衰减 + 仪器响应函数。
用于「荧光寿命」模式的 MEM 分布拟合与寿命分量计算。

### 04-3D扫描EEM-RB-Lu
Spectracle/FE30 「3D 扫描 扫描」格式，EX 500–600 nm × EM 200–900 nm 的激发-发射矩阵，RB/Lu 体系。
用于「3D 扫描」模式的曲面 / 等高线 / Waterfall。

### 05-数据比较-浓度梯度
26 条发射光谱 + `说明.xlsx`（列：`编号 / RB浓度 / Ce6浓度 / L8i浓度`）。
用于「数据比较」模式：按浓度作横轴，把每条谱压成一个读数（峰强 / 峰面积 / 指定波长）。

## 注意
- `说明.xlsx` 里的 `编号`（R1/S1…）要与 CSV 文件名开头的编号对得上，否则该样品不参与比较。
- 目录名带序号前缀只是方便按模式排序；GUI 选文件夹时选到具体子目录即可。
- 这些是真实实验数据，含未发表的测量结果，不要外传。
